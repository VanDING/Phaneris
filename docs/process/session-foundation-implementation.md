# Session 基础架构收敛实施记录

目标：以 Session 为对话自有持久化内容的归属单位，沿现有产品存储、Runtime Host、事务内核和平台适配边界收敛实现。保持产品功能与执行安全协议，不重写系统。

## 实施批次

1. 消息身份与恢复：统一模型结果身份，修复已提交事实缺少产品快照时的读取；兼容历史消息身份。
2. 文件生命周期：分支复制会话自有文件，导出使用可移植引用，导入统一字段策略与失败回滚。
3. 产品写入：收敛 SessionManager 元数据写入口，统一外部元数据比较与合并字段。
4. 会话私有存储：草稿与 Artifact 私有文件按 Session 归属；保留旧数据兼容与回滚路径，明确执行证据的保留策略。
5. 清理与文档：移除失效兼容入口，减少重复映射，更新架构说明和验证证据。

不在实施范围：拆分 Runtime 数据库、改变未知副作用处理、恢复运行中进程、移动用户工作目录和共享业务资源、发布版本或推送远端。

## 先行失败矩阵

| 场景 | 必须避免的失败 | 验收证据 |
|---|---|---|
| 模型提交后投递产品事件 | 同一消息具有不同 ID、重复计费、重复显示 | 实际 Runtime + SessionManager 事件/消息身份对照 |
| 提交后产品快照缺失并重启 | 已提交正文不可见、重发外部调用、丢失已有 UI 信息 | 重启前后消息与事件、用量对照 |
| 历史不一致 ID | 修复导致原引用/已读/分支失效、重复语义消息 | 历史快照兼容验证 |
| 含文件分支 | 路径已改而文件缺失、源会话被修改、失败后遗留子会话 | 文件清单与 SHA-256、回滚结果 |
| 跨目录导入 | 引用残留源路径、字段意外丢失、导入失败留下半成品 | 目录与字段差异、源目录不可用后的读取 |
| 元数据与消息追加交错 | 磁盘旧快照覆盖消息、清空语义丢失 | 重载后的消息和字段对照 |
| 外部编辑项目和看板列 | 被误判自身写入、后续保存覆盖外部修改 | 文件修改及重载对照 |
| 草稿兼容与迁移 | 读取错工作区、旧内容被破坏、空草稿复活、迁移失败丢数据 | 新旧存储、重启/删除/打包对照 |
| Artifact 归属与删除 | 修订或工作副本丢失、越界移动用户文件、悬空 owner | 修订哈希、列表与操作结果 |
| 成果接受 | 私有文件的权限策略泄漏到用户最终文件 | 实际接受产物及默认用户文件权限对照；原生 Linux 权限另行验证 |
| 执行证据保留 | 删除未知副作用证据、回执导致已删会话复活 | 删除前后执行事实与目录对照 |
| 前端加载与清理 | 流式消息被快照覆盖、移除仍使用的入口 | 现有会话读取与规划流程验证 |

所有流程验证只使用隔离 fixture。已有用户数据不执行批量删除或原地迁移。

## 验证夹具维护

组合验收暴露了两处既有夹具偏差，修正限定在验证代码：

- Bash 成功输出不再被当前产品认可为完整指导交付证据，旧 U15 场景断言更新为当前安全规则，未放宽产品实现。
- 模拟模型正确提取 provider 文本块，并按最后一条显式 fixture 请求分类，避免历史连续性上下文里的旧指令触发旧工具调用；失败时也保存 provider 请求诊断。

文档门禁补齐本轮文档状态/索引及两条已有孤立 Run 文档链接。未修改门禁阈值、忽略项、依赖 pin 或版本号。

## 数据与交付边界

所有迁移、删除、失败注入和恢复验证均使用隔离 fixture。未对用户真实会话执行批量迁移、删除或改写。旧格式备份和回滚操作见[Session 存储契约](../architecture/session-storage.md)。真实外部模型/OAuth、Office 视觉布局和 Linux 原生文件系统未在本机验证。
