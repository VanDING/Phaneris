# Pi 1.1.0 / Craft 0.14.1 实施前失败矩阵

记录日期：2026-10-08。详细契约沿用 [批准的计划](./pi-sdk-1.1.0-upstream-0.14.1-plan.md)。本文件和验证夹具先于生产代码建立。

| 批次 | 故障注入与失败条件 | 验收 |
| --- | --- | --- |
| B0 | 延迟真实子进程的 policy 回复；并发初始化/标题查询越过工具同步；凭据读取期间重复 spawn；退出、销毁后等待永久挂起 | 首轮/次轮工具一致；同一启动 promise；外部请求在 sync_tools 后；有限时间拒绝 |
| B1 | 混装 SDK；Azure 旧 provider 找不到或 API 被改名；旧会话回落错误账户；失败/取消 settled 不完整；无效 duration；源关闭后仍能调用；工具负选择泄漏；OAuth 刷新与取消丢失凭据；codemode 图片/console 或打包 worker 丢失 | 精确版本图、真实 JSONL/回环 provider、独立权限与 T1/T2、刷新持久化、包外资源 |
| B2 | authRetry 重做决策与记账；hidden/任务重评级；冷热跨连接；超硬 deadline；日志轮转漏读/重复 outcome；零与未知费用混淆；远程 GET_USAGE 读错服务器；长名称不可访问 | 请求次数、冷热 key、认证 RPC、日志统计与 UI 产物 |
| B3 | 短确认带附件降档；纠正/重大操作降档；用户 Low 被升 High；取消或用户改档后旧结果覆盖；前文超过预算或泄漏附件正文 | 真实宿主轮次、元信息、档位上限、后续关联 |
| B4 | intent 被丢掉或注入未声明 schema；末尾证据丢失；缺答案/批次失败仍返回片段；标题缺口突破预算；取消后启动摘要；结构化数据或原文丢失；读取尝试被算成功；副作用重放 | 唯一原文哈希、完整长度、fallback、全链路 T1/T2、读取 outcome 和期限 |
| B5 | 既有门禁退化；开发成功而随包失败；历史 fork/compaction 不可用；旧报告改名伪装新证据；性能目标未测便声称完成 | 最终源码、命令退出码、独立报告与截图、SHA-256、未验证范围 |

验证使用隔离配置、惰性工具和回环服务，不访问真实用户历史。离线决策夹具只验证策略契约，不证明真实模型判断质量。
