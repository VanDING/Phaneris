## 1. 目标与已确认边界

用户进入助手对话界面后，可以持续与助手协调工作，并在右侧从整个工作区的 Board 进入具体 Session，再返回工作总览。

| 已确认决定 | 规划约束 |
| --- | --- |
| 进入助手对话界面，默认全屏对话 | 初始右侧关闭，助手占满该界面的内容区域 |
| 可以呼出侧边栏 | 打开后为助手对话与 Board 并排，助手保持在左侧 |
| Board 默认 Kanban，可切换日历、甘特图 | 直接复用现有三种视图，同一份 Session 数据采用不同呈现 |
| 通过 Board 进入对应会话 | 右侧由 Board 切换为该 Session，左侧仍为原助手对话 |
| 右侧会话可以返回 Board | 在右侧恢复 Board，不替换左侧助手，也不退出助手界面 |
| Board 范围为整个当前工作区的全部任务与会话 | 不默认收窄为助手派发或接管的工作；现有可见性及历史口径的细节在实施前核对 |
| 以 Session 为本体 | 一张卡对应 Session；不区分两类任务卡/会话卡，不建立独立任务存储或额外关联流程 |
| 沿用现有状态与运行事实 | 不新增并列的用户任务状态体系；运行信息按需提示，不要求用户维护第二套生命周期 |

本交互仅在助手对话界面内成立，不将右侧面板扩展为所有普通页面的全局入口。助手、普通 Session 和独立 Board 既有入口的整体改版不属于本计划。

## 2. 展示状态与操作路径

| 当前展示 | 用户操作 | 下一展示 |
| --- | --- | --- |
| 助手全屏对话 | 呼出右侧 | 助手 + Board |
| 助手 + Board | 切换 Kanban / 日历 / 甘特图 | 助手 + 对应 Board 视图 |
| 助手 + Board | 打开某个 Session | 助手 + 该 Session |
| 助手 + Session | 返回 Board | 助手 + 原 Board |
| 助手 + Board 或 Session | 关闭右侧 | 助手全屏对话 |
| 助手界面 | 关闭助手 | 返回进入助手之前的应用界面 |

右侧同一时刻显示 Board 或一个 Session；本期不增加三栏常驻、多会话标签组或 Board 独占全屏的主流程。返回、关闭和切换视图均为展示操作，不自动启动、暂停、取消、重试或完成会话。

左侧助手的会话身份、历史、草稿、附件及阅读位置不因右侧切换而重置。右侧复用完整普通会话能力，包括消息、输入、附件、活动及现有授权交互；左右输入、配置、停止和批准操作必须指向各自 Session。

## 3. Board 返回与展示连续性

Board 进入 Session 后，需保留原视图及浏览状态：

- 共用状态：工作区、项目筛选、搜索、已选 Session 及分栏宽度。
- Kanban：列的浏览位置、滚动和子项展开情况。
- 日历：月/周等已有子视图、当前日期范围与浏览位置。
- 甘特图：时间范围、缩放、展开及滚动位置。

从右侧 Session 返回时恢复原位置，数据仍按最新 Session 事实更新。例如，会话状态或排期发生变化后，应在原 Board 范围内显示更新，不能用旧展示快照覆盖事实。

默认全屏及首次 Kanban 遵循第 1 节。反复关闭、重开右侧以及退出后再次进入时，哪些浏览偏好继续保存，属于实施前待定细节；保存偏好不能使进入助手时自动打开右侧。

当前 Board 查询会过滤隐藏、归档及 taskDraft 会话。用户确认的“整个工作区”是范围决定；这些现有过滤、助手自身的呈现、父子及接续会话如何收纳，需要明确口径，不应为凑全量而直接取消既有过滤。

## 5. 布局及助手联动的待定项

核心四步交互已确认；以下细节尚未确认，不能将本节建议当作额外功能承诺：

| 待定项 | 建议及约束 |
| --- | --- |
| 默认分栏比例及调宽范围 | 右侧承载完整 Board/会话，需要可用工作宽度；复用设计体系和调宽机制，通过真实三视图内容确定，不沿用窄浮层尺寸假设 |
| 窄窗口 | 确定两栏不足以阅读时的降级方式，保持助手身份、右侧选择和返回路径；具体断点及单区切换方式待定 |
| 当前对象引用 | 可向助手提供当前右侧 Session ID 等轻量界面上下文，使“看看这个会话”有所指；原文按需读取，不默认复制完整历史。是否纳入本版及准确契约待定 |
| 现有“更多”总览 | 明确 Board 入口与当前/交付物/历史及消息渠道管理入口的分工；既有能力不因本计划自动删除或迁移 |
| 焦点与按键 | 两个输入区的当前操作对象、打开/返回/关闭的焦点恢复，以及 Esc 的处理层级需一致；不能让右侧操作误发给助手或反向串用 |

界面可查看某个 Session，不改变助手对该 Session 的管理归属与执行权限；沿用 0.6.2 已有契约。
