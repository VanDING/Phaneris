# 常驻助手：首包失败矩阵

Status: accepted — 用户于 2026-11-03 授权新分支开始实施；本文先于产品代码编写。

本包实现 workspace 记忆 Host 服务、持久修订/退出、来源回看和远程 RPC。它是 [0.6.x 规划](../architecture/resident-assistant-0.6-roadmap-2026-11-03.md) 的底座，不代表完整 0.6.0 已完成。助手 Session、角色工具、委派、上下文分段和品牌前台按后续包接入。

| ID | 失败方式 | 预期结果 |
| --- | --- | --- |
| RM01 | 两个 workspace 使用同样的 key 和消息 ID | 独立记忆；连接不能操作另一个 workspace |
| RM02 | 无 workspace 上下文、错误 workspace 或畸形 payload | 写入前拒绝，不创建越界数据库 |
| RM03 | 引用缺失会话/消息或越界路径 | 拒绝，不生成无来源记忆 |
| RM04 | 把助手回答/内部转投当用户陈述 | 拒绝 user_stated；不确定材料仅为 inferred 候选 |
| RM05 | 重放同一请求，或复用请求 ID 改内容 | 原操作只执行一次；不同内容冲突 |
| RM06 | 用户纠正后旧修订迟到 | 乐观版本冲突，最新内容不被覆盖 |
| RM07 | 同一项目更新、不同项目同名 | 同范围不重复，同名项目范围并存 |
| RM08 | 冷却、失效或期限结束 | 不进入默认当前检索；可查看明确状态 |
| RM09 | 忘记后重放旧请求、修改 key、重新摄取同一来源 | 不泄露旧正文，不重新创建当前事实 |
| RM10 | 忘记后直接读旧来源 | 正常来源入口拒绝，不绕过退出标记 |
| RM11 | 重开数据库/Host 后再查询、再次提取 | 修订、版本和 suppression 持续有效 |
| RM12 | 同时基于旧版本修订 | 仅一次成功，失败者明确冲突 |
| RM13 | 中文两字查询及特殊 SQL 字符 | 字面检索正确，参数化查询不改变范围 |
| RM14 | 分页期间写入或跨过有效期 | 游标失效要求重查，不混合不同版本或有效性状态 |
| RM15 | 变更事件、读取退休条目，key 也含语义 | 事件不携带正文；遗忘条目不返回内容、语义 key 或来源 |
| RM16 | 普通会话和原文件 | 不改原 Session、全局偏好和 AGENTS.md |

验收采用真实 WebSocket RPC、SQLite、两个隔离磁盘工作区和真实 JSONL 来源；不调用付费模型，不访问用户真实历史。生成带源代码身份和文件哈希的可重验 manifest。模型召回质量、实际上下文退出、前端和完整委派留在后续包，不能由本包宣称通过。

## P2a：助手身份与角色（先于本包代码）

| ID | 失败方式 | 预期结果 |
| --- | --- | --- |
| RA01 | 多客户端同时首次取得助手 | 同 workspace 只有一个已持久特殊 Session |
| RA02 | 另一个 workspace、重启或普通会话标题相同 | workspace 独立，重启恢复身份，不按名称判断 |
| RA03 | 普通 create 参数伪造角色/preset、导入带角色的历史 | 不产生第二个助手或绕过受控入口；导入只是普通历史会话 |
| RA04 | 删除、归档、完成特殊 Session | Host 拒绝；普通 Session 的原操作保持 |
| RA05 | 主助手被设为 allow-all | shell、文件写入、全局偏好、外发和原消息投递依旧被角色禁止 |
| RA06 | 不经过前置检查直接调用代理或 durable prepare | Host 再次拒绝越权工具，无实际执行 |
| RA07 | 工具发现、动态工具重建或重启 | 模型目录只暴露允许工具，源工具不能混入 |
| RA08 | 独立 prompt 重复人格、压过协作规则 | 角色职责独立，沿用既有偏好/项目规则来源 |
| RA09 | 模型经记忆工具访问其他 workspace 或遗忘来源 | 工具无 workspace/path 参数，Host 绑定所属 workspace，遗忘后不能回读 |
| RA10 | 新工具泄漏到普通会话或缺少 Host 回调 | 普通实际工具目录保持；缺回调明确不可用 |
| RA11 | 普通聊天、Session 创建/状态与协议 | 兼容；新助手接口走远端 Host 路由 |

本包先接身份、角色和只读记忆工具；完整 Worker 配置与可靠委派随 P2b/P3 接入。实际模型上下文退出和品牌前台继续按 P4/P5 验收，不以角色边界脚本冒充真实模型质量验证。

## P2b/P3a：配置与持久委派（先于本包代码）

| ID | 失败方式 | 预期结果 |
| --- | --- | --- |
| RW01 | 重放请求、并发重试、相同 ID 改内容 | 同一 Worker；不同 payload 明确冲突 |
| RW02 | 外 workspace 调用、普通 Session 冒充助手 | 在创建 Worker 前拒绝 |
| RW03 | 连接、模型、thinking、目录、项目、Source、Skill、插件不存在或不支持 | 明确失败，不静默换模型/丢配置；不启动 Worker |
| RW04 | Worker 请求比助手更宽的权限 | 夹至助手当前权限；请求与实际配置同时可查 |
| RW05 | Sources 与 Skill/插件依赖混合 | 验证完整依赖，最终显式配置，Skill 随首次输入保存 |
| RW06 | Worker 交付、出错、取消后迟到 | 带 Worker/委派归属的持久成果；不伪造用户消息；终态不复活 |
| RW07 | 执行未结束就再次提交 | 默认串行，后续工作排队；取消排队任务不启动它 |
| RW08 | Host 重启、创建/投递边界中断 | 已完成结果仍可查；未确认执行不自动重复副作用，展示需恢复状态 |
| RW09 | 把任务投递或旧 Session 消息当真人记忆/授权 | 结构化来源保留；禁止旧投递入口向助手注入用户指令 |
| RW10 | 大量记录与成果 | 有界分页与成果摘要，原文以源 Session/message 回看 |
| RW11 | 助手不知道可用配置，或配置目录泄漏凭据 | 只读分页目录返回模型/资源能力，不返回 API key、endpoint 凭据或其他 workspace 内容 |
| RW12 | 接受后修改默认配置或提高助手权限 | 已接受的配置不随默认值漂移、不自动提权；权限收紧继续生效，资源依赖变更明确失败 |

本包验收使用生产 Host、真实 RPC/SQLite/JSONL 和回环模型服务。自动唤醒助手、完整故障自动续跑、逻辑上下文段和前端收件箱仍分别验收；不能把持久成果查询等同于已自动交付给用户。

## 普通 Session 复用与委派收敛（先于本包代码）

| ID | 失败方式 | 预期结果 |
| --- | --- | --- |
| RS01 | 指定已有普通 Session 继续工作 | 保留身份、历史、名称、原有任务关系与配置，不另建执行会话 |
| RS02 | 同一 Session 承担连续委派 | 每次输入和成果独立引用，旧成果不被后续轮次覆盖 |
| RS03 | 目标跨 workspace、特殊助手、隐藏、归档、忙碌或需要恢复 | 接受前拒绝，不改目标、不投递 |
| RS04 | 请求配置不同于已有会话，或超出助手权限上限 | 明确拒绝，不静默重配已有会话 |
| RS05 | 排队期间用户继续会话或改配置 | 普通交互保持；旧委派启动前失败，不覆盖新输入或抢占执行 |
| RS06 | 未提交/取消的委派输入进入模型恢复历史 | 排除尚未提交的输入，不能因用户手动聊天而提前执行 |
| RS07 | 委派数据库与 Session 各保留一份正文/成果 | 活跃回执只存身份、投递状态和引用；输入/配置快照及成果正文由 Session 保存 |
| RS08 | 旧完整记录升级、迁移中断、原 Session 缺失 | 保留迁移归档；可恢复的内容归入原 Session，缺失来源明确待处理；不自动执行或复活已删除会话 |
| RS09 | 创建、保存输入和接收回执之间退出/重试 | 稳定关联找回原 Session/输入，不重复创建或提交 |
| RS10 | 目标有另一笔未结束委派或无关轮次完成 | 拒绝争用；仅属于原输入的完成事实能生成交付结果 |
| RS11 | 接管仍绑定 Tasks 调度运行的 Session | 明确拒绝，不与既有任务调度器争夺执行所有权 |

## P4a：普通历史来源目录（先于本包代码，2026-11-04）

本包先接通可重建的来源目录及实际助手检索，不自动把历史提升为事实。它是工作集、Context Manifest 和 P3b 消费入口的来源基础；不宣称已移除 provider 旧历史或实现逻辑换段。

| ID | 失败方式 | 预期结果 |
| --- | --- | --- |
| RH01 | 两 workspace 同名消息与项目 | 连接、检索和索引所有权隔离 |
| RH02 | 尚未索引全部历史就查无结果 | 有界推进并返回 pending/不可读覆盖，不把无匹配说成不存在 |
| RH03 | 已归档、隐藏或很旧的普通 Session | 默认纳入；仅特殊助手不作为普通历史来源 |
| RH04 | 委派、转发、助手回答与真人输入混合 | 保留角色及 inputSource；不升级为用户陈述或授权 |
| RH05 | 同项目词汇、不同项目决定 | 项目/Session 过滤准确，中文短词及 SQL 特殊符号按字面检索 |
| RH06 | 改写消息、追加消息、改变项目 | 下次增量刷新只处理变化的 Session；旧内容和范围不继续返回 |
| RH07 | 源 Session 删除、损坏或消息缺失 | 撤回旧索引；不可读状态明确，无旧摘要回退 |
| RH08 | 忘记后检索、重建来源目录、Host 重启 | suppression 持续生效，不通过索引或来源读取复活 |
| RH09 | 分页途中索引或 suppression 改变，或替换查询条件 | 拒绝旧游标；稳定页不重不漏 |
| RH10 | 搜索后源内容改变、继续读旧范围 | 带 contentHash 的精确读取拒绝版本变化 |
| RH11 | 附件只有引用、JSONL 有坏行或共享引用损坏 | 覆盖明确不完整；不声称已理解附件或完整读过坏来源 |
| RH12 | 编译后的 Pi 实际调用检索 | 生产 Host 回调返回普通历史；实际 provider 请求可核对来源、内容身份和范围 |
| RH13 | 普通会话与原文件 | 普通工具目录不新增助手历史能力，源 JSONL 不被索引器改写 |
| RH14 | 普通历史含 plan/auth-request 角色或损坏的共享快照引用 | 合法角色仍被纳入；单个坏来源不能阻断其他检索或冒充完整覆盖 |
| RH15 | 工具消息正文为空，输入/结果另存在结构字段 | 工具输入与结果仍可检索/精确回读，结果变化使旧哈希失效；不升级为真人事实 |

验证以生产 bootstrap、RPC、SQLite/JSONL、Host 重启和真实 Pi 子进程配合回环模型服务完成，保留机器结果、实际请求、数据库和源快照；配置及内置帮助文档留在 `.cache/verification`。

## P4b / P3b / P5 完整闭环（先于本包代码，2026-11-04）

| ID | 失败方式 | 预期结果 |
| --- | --- | --- |
| RC01 | 记忆结果及其转述已经进入 SDK 历史后遗忘/修订/到期 | 下一实际 provider 请求退出旧材料及派生回答；原 Session 身份与档案保持 |
| RC02 | 原来源改写、删除、抑制；Host/子进程重启 | 重新核对依赖，不靠旧工具结果或压缩摘要复活 |
| RC03 | provider 请求在途时纠正/遗忘 | 旧响应保留计量与执行证据，但不成为可交付答案或继续调用工具 |
| RC04 | 主助手请求准备失败或上下文不可用 | 明确失败，不回退到未过滤的 Pi 历史 |
| RC05 | 切换项目/议题、换模型、长期增长 | 稳定产品 Session 下换段；原始约束由引用恢复，过时过程材料退出 |
| RC06 | 必需原始要求超过实际容量 | 请求前明确阻塞，不截断或静默丢要求；可显式调整工作集 |
| RC07 | 换段中到达新的用户输入 | 原输入各保存一次，按队列进入新段；不被摘要或旧段覆盖 |
| RC08 | Context Manifest 与实际请求不一致 | 以 Pi 请求诊断为交付证据，含段、材料身份和容量；草稿不当已发送 |
| RC09 | 模型提取、修改或忘记记忆 | 经过既有版本/来源/suppression 校验；推断为候选，不能制造用户批准 |
| RE01 | 工作完成时助手空闲/忙碌/客户端离线 | 持久记录结果引用；空闲用原 Runtime 唤醒，忙碌用户输入优先；不复制用户气泡 |
| RE02 | 读了事件但未进入模型、模型失败或中断 | 不推进已处理/已交付；恢复不重复派发工作 |
| RE03 | 处理成功后、持久化交付前崩溃 | 按稳定输入/结果身份核对，恢复已有交付，不复制回答 |
| RE04 | 相同完成事实重放、ACK、取消后迟到结果 | 事件去重；ACK 不唤醒；取消不复活 |
| RE05 | 执行侧原权限/ask_user 问题 | 助手展示原请求引用，答案只回原 Session/request；助手工具不能代答 |
| RE06 | Host 重启后存在未知执行副作用 | 保留原 Runtime 恢复屏障，不因唤醒/回执再次执行 |
| RU01 | 首次进入、重新展开品牌入口、切换 workspace | 默认同一助手；普通 Sessions 有入口，无跨 workspace 残留 |
| RU02 | 收起/展开时存在草稿、滚动、运行中的工作 | 现场保留，不取消工作，不创建第二助手 |
| RU03 | 打开记忆/上下文/交付详情，按 Esc | 单栏对话为主，详情按需显示，按层关闭并恢复焦点 |
| RU04 | 来源/权限/成果卡片 | 跳转原 Session/原请求；不出现可让助手代批的入口 |
| RU05 | 前台与远端 API、普通会话回归 | 共享同一 Host 状态，普通聊天/Tasks/导入导出功能保持 |

先执行生产 Host / 编译 Pi / 回环 provider 的闭环 E2E，再验收前台。真实付费模型质量、服务器托管产品化、双 Host 所有权和主动巡视继续按原路线留后，不以 fixture 或界面存在冒充验收。

补充可执行边界：RC02 检索旧委派输入与助手转述时也核对依赖；RC06 大量必须原文在 provider 前阻塞，显式调整议题后同身份恢复；RE03 在回复落盘后撤去消费终态，冷启动按原 run/message 身份恢复，不新增模型请求。

终验补充：RC08 为每次请求固定材料/范围/记忆状态，不把后续工具结果回填到先前 Manifest；RC09 候选提取结果及其转述也登记退出依赖；RU03 验证 IME Escape、前后台焦点归属与窄窗名称/Tab 隔离；RU05 遗忘清除已打开来源预览并拦截迟到旧读取。对应红灯和终验入口见实施记录末节。

## P4c：增量提取检查点（先于本包代码，2026-11-04）

提取复用主助手 Runtime，不新增后台模型循环。一次主轮次最多读取一个有界来源片段；检查点仅保存引用、版本、范围、结论与候选引用，来源正文仍归原 Session。

| 场景 | 失败触发 | 必须观察到的行为 |
| --- | --- | --- |
| RX01 | 普通 Session 或未开始主轮次调用维护 | 工具不向普通 Session 开放；无实际轮次不能确认进度 |
| RX02 | 启动、无新材料、重复维护 | 无启动模型调用；覆盖状态区分索引与提取，已确认版本不重复抽取 |
| RX03 | 大消息与同轮无限取下一批 | UTF-16 有界分片；同轮最多一个片段，剩余材料明确待处理 |
| RX04 | 片段取出后中断、重启或重复 ACK | 未确认片段保留，重启可续用；相同 ACK 幂等，不同结论冲突 |
| RX05 | 伪造候选引用、未读取片段就 ACK | 只允许本轮实际读取的检查点；候选必须为该来源当前哈希下的推断候选 |
| RX06 | ACK 前来源改写、项目变化、删除或遗忘 | 旧 ACK 拒绝；新版本/新范围重新排队，suppression 不随重建消失 |
| RX07 | 隐藏/归档普通来源、跨项目/工作区和内部归因 | 普通来源纳入，scope 不混用；内部记录不升级为用户陈述，无跨工作区内容 |
| RX08 | 无可提取事实或只有未解析附件 | 可明确记录无候选；附件仍标未解析，不把已处理文字冒充理解附件 |
| RX09 | 实际模型取片段、写候选、确认 | 使用生产 Host、编译 Pi、原 Runtime；后续请求看见实际片段和候选，候选不进入 active 召回 |
