# Harness 系统演进实施前失败矩阵

Status: accepted — declared before production changes; implementation authorized on 2026-10-26.

基线：`ab0282111`，分支 `codex/harness-system-evolution`。依据[系统演进方案](../architecture/harness-system-evolution-2026-10-25.md)。以下情形在实现前确定，优先通过真实 Pi/Host/SQLite、文件和 Artifact 的完整链路验证；模型响应采用 loopback fixture 时只证明契约，不证明真实模型质量。

| ID | 可能失败的完整任务情形 | 验收结果 |
| --- | --- | --- |
| HE01 | 用户已选技能，第一轮仍只有路径或必须先读说明才能写草稿 | 第一轮请求包含准确原文、作用域和版本；原生写工具可直接产生草稿 |
| HE02 | 全局/工作区/项目技能重名、技能更新或丢失 | 按既有优先级解析，每轮反映当前版本；缺失明确说明，独立工作仍可继续 |
| HE03 | 大技能、根规则或 source 指导超出准备空间 | 原文完整性准确，保留范围和读取入口；不伪装全文或自动语义摘要 |
| HE04 | 一次选择永久激活全部技能或跨任务累加 | 仅当前显式选择/任务接续适用；不枚举技能库或语义路由 |
| HE05 | 失败请求、压缩或重建后已选指导丢失 | 指导随有效请求恢复；准备不被误认为已交付 |
| HE06 | source 只有 resources/prompts，或暂时断连 | 能力和状态准确；正常使用不要求读原始配置；可独立工作继续 |
| HE07 | 工具家族由名字误判，选择专业能力仍需要多轮发现 | canonical 定义明确归属；已选能力就绪，长尾发现带回 schema 和指导 |
| HE08 | Windows 不可用后端被预展开，或目录查询意外激活工具 | 不可用原因与替代入口明确；目录观察不激活工具 |
| HE09 | 小型全文读取反复产生完整源副本；分段内容跨版本拼接 | 小结果精确保留，不多存完整源文件；需一致范围时保存本次字节快照 |
| HE10 | 大列表/结构化结果只能看头尾，程序侧数据被裁剪 | 返回结构、字段/范围/分页状态和恢复入口；完整程序值及媒体顺序保留 |
| HE11 | 多个大结果挤掉上下文或随完成顺序改变视图 | 共同请求容量口径、稳定批次分配；无输出或恢复空间时准确处理 |
| HE12 | 文档/Artifact 检查只给 UI 路径，模型无法查看；编辑后仍报告旧检查 | 返回当前版本与可用视觉材料/范围；检查与版本对应 |
| HE13 | 长任务中段要求不在首条和最近八条，接续遗忘 | 当前任务事实、要求原文引用和成果入口共同接续；可按消息范围回看 |
| HE14 | 模型工作记录覆盖真实批准，或旧 Artifact 覆盖用户新编辑 | 事实与模型判断分开；当前版本可见，批准仍查原记录 |
| HE15 | 权限等待持有效果锁，独立读取也停住；相关写后读越序 | 等待授权不持有效果锁；相关调用顺序、最终目标与 T1 一致 |
| HE16 | 阻断/停止后仍执行，或未知效果被盲目重试 | 保留取消结算与未知效果恢复；不重复业务动作 |
| HE17 | 辅助分类阻塞首请求或悄悄降低用户 thinking | 通用路径直接使用用户有效选择；可选建议异步、过期失效 |
| HE18 | 精简 prompt 造成技能、产品操作、权限或工具指导缺口 | 适用指导随能力到达，实际请求可检查；权限保持原契约 |
| HE19 | 新接口与旧 prerequisite/预算/选择状态长期并行维护 | 新路径接通后退出对应重复路径；兼容数据仍可读取 |
| HE20 | fixture 通过被宣传成质量提升，或验收没有可重复成果 | 保存命令、源身份、实际请求、文件/预览和未验证范围；质量单独报告 |
| HE21 | Pi 真正缩减历史后，下一轮完整事实重放撤销压缩；重启或跨压缩边界的 T2 丢失 | SDK 压缩前缀持续有效，只收敛未覆盖的事实；新用户输入始终保留，跨边界未配对工具结果走完整事实恢复；日志重开后可重复验证 |

代表任务基线：已选研究技能写报告、多源 PDF、公式表格、修改已有 Office、压缩后继续、中途纠正/停止和跨文件代码修改。先保存可重复任务输入、有效模型配置与成果检查口径；没有运行真实 provider 时明确 NOT RUN，不制造完成率或质量收益数字。

本轮只使用隔离合成工作区，不改用户连接、设置、真实历史或外部服务。现有打包验收改动属于独立工作，不包含在本实施中。
