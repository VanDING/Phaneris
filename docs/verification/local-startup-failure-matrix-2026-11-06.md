# 本地启动收缩：实施前失败矩阵

日期：2026-11-06。用户已要求执行本轮完整方案。所有验收使用隔离配置、合成会话和本地测试资源；不改写个人数据库、配置、既有备份或已安装客户端。

| ID | 失败方式 | 必须验证的行为 |
| --- | --- | --- |
| LS01 | 每次启动扫描数据库全页 | 正常启动只打开/迁移数据库和处理未结算记录；完整检查仍可明确调用 |
| LS02 | 启动后或长时间空闲生成数据库备份 | 启动、等待和关闭均不生成默认每日快照；没有六小时维护计时器 |
| LS03 | 配置初始化生成、覆盖或裁剪日期备份 | 普通配置初始化不产生自动备份；既有备份不动；原子写入保留 |
| LS04 | 取消自动备份后，损坏恢复错误地依赖新快照 | 损坏原文件保留；已存在的可用恢复点仍可读取；健康工作区可继续使用 |
| LS05 | 数据库真正无法打开却被当作健康 | 原有存储错误分类、隔离和必要恢复继续工作，完整检查有明确结果 |
| LS06 | 已完成或归档历史会话被激活 | 冷启动仅建立目录元数据；没有执行槽、driver、正文加载或逐会话账本重算 |
| LS07 | 用 `done` 跳过实际未结算操作 | 恢复依据未结算操作/持久回执，用户状态不能放过未知副作用 |
| LS08 | 打开历史会话不能恢复权限或继续聊天 | 打开/执行按需激活，权限模式/上一个模式恢复，正文与已保存元数据保留 |
| LS09 | 新建、导入、分支和跨会话投递绕过按需激活 | 这些路径使用同一运行时激活边界，停止、排队、结算和关闭继续正确 |
| LS10 | 运行时重复注册观察者或重复投递 | 同一会话只激活一次；释放/重建后的会话重新绑定且没有旧订阅 |
| LS11 | 归属校验仍生成全会话列表 | 已知会话按 ID 从注册表查询，跨工作区请求拒绝，非法 ID 仍拒绝 |
| LS12 | 启动/重连逐个拉取所有历史会话权限 | 列表快照先展示；只有需要继续操作的会话才校准动态权限 |
| LS13 | 列表序列化重复读取助手位置映射 | 路径在归属已确定时计算/保存；重复 getSessions 不读每条位置文件 |
| LS14 | 冷列表用量为空或打开后覆盖正确统计 | 保留已保存的用量摘要；打开/运行后按账本更新；不为历史列表重放账本 |
| LS15 | 默认状态图标首读异常后永久变空心圆 | 短暂读取失败能在不切换页面的情况下恢复；正常缺失不产生重试循环 |
| LS16 | 图标请求在切换工作区/卸载后写入旧状态 | 旧请求不污染新工作区；并发读取共享，错误不缓存为永久缺失 |
| LS17 | 图标恢复引入无限轮询或重试风暴 | 重试有界，断线恢复由现有连接状态驱动；关闭/卸载取消待办 |
| LS18 | 无自动化的工作区仍有每分钟调度器 | 没有有效启用 cron/page refresh 时不启动；动态增删配置正确启动/停止 |
| LS19 | 精简导致后台服务漏掉用户已配置的自动化 | headless、启用的事件/定时自动化、页面刷新在没有 UI 连接时仍工作 |
| LS20 | 消息网关初始化阻挡业务窗口 | 事件转发先接好，已配置网关在窗口准备后启动；禁用时不连接 |
| LS21 | 规模增大再次触发平方级成本 | 数百/上千完成会话的真实 RPC 权限校验不调用 getSessions；保留可复跑数据与计数 |
| LS22 | 打包客户端仅切换页面后才显示正确状态 | 实际 Electron main/preload/renderer 冷启动，首次可用界面已有正确状态图标 |
| LS23 | 关闭时扫描/激活全部历史会话 | 关闭只排空已激活工作与已有产品写入，不创建新执行槽 |
| LS24 | 修改被错误描述为已部署 | 保存源代码、构建身份和 E2E 结果；工作树验证与安装版区分报告 |
