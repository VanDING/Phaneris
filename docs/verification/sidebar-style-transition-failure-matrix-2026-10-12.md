# 侧栏按钮与状态过渡：失败矩阵

状态：实施前定义。基于已合并的 `da2cebb3d`，按用户最新偏好改为两态共享紧凑间距。

| 场景 | 可能失败 | 验收 |
| --- | --- | --- |
| 新建会话 | 按钮仍填满 36px 首行，紧挨下一项；缩短后单独居中使顶线低 4px | 默认按钮与普通导航同为 28px；整个上部导航组上移首行中心内距（默认 4px），按钮顶线对齐面板上沿，与下一项保留约 8px 留白；底部控件保持原锚点 |
| 两态位置 | 展开约 2px、收起 8px 行距，顶部 padding 和图标内距同时切换 | 两态默认同为 28px 行、2px 行间距；同一图标列、相同顶部内距；收起按钮为 28px 正方形并在 48px 栏宽内居中 |
| DOM 连续性 | Tooltip 的条件包装重新挂载按钮，CSS 无法插值、键盘焦点丢失 | 两态使用相同按钮 DOM；收起 Tooltip 正常，展开不显示它；焦点保持在原按钮 |
| 样式过渡 | 只有外部栏宽在动，按钮宽度、文字和底部控件瞬间替换 | 真实窗口逐帧记录按钮宽度中间值、标签淡入淡出、头像与设置位置；图标列连续稳定 |
| 快速反向 | 上一个动画结束时覆盖较新的切换，闪到错误状态 | 过渡期间快速反向，从当前几何继续；最终位置、栏宽和按钮比例正确 |
| 子菜单 | 收起后子菜单遗留空白，或展开/收起改变已保存的展开选择 | 子菜单退出/恢复连续，原展开选择保持；导航与上下文菜单仍可操作 |
| 放大字号 / 密度 | 统一默认行高裁切文本，图标栏变长方形或图标左右跳位 | 展开随字号/密度增长；收起仍正方形；主导航外层行槽保持字号/密度对应的中心位置 |
| 触摸 | 改成 28px 后丢失 44px 目标 | coarse pointer 控件仍 ≥44px，60px 栏宽居中；首行与面板标题同中心 |
| 减弱动态 | 新 CSS 动画不遵循系统减少动态偏好 | 减弱动态时直接到目标状态，没有空间过渡；所有操作仍可用 |
