# Default 主题收敛与颜色契约修复

截图、trace、构建 bundle 和其他验证产物不入库；保留本记录与验证脚本，执行脚本可重新生成。

用户目标：仅保留 Default 产品主题，保留浅色 / 深色 / 跟随系统与字体偏好；默认视觉与已批准的 Run 配色协调。

## 修改前的失败矩阵

| 场景 | 必须保证 |
| --- | --- |
| 旧 Geek / Cyberpunk / Ink / 自定义选择 | 产品偏好统一解析为 Default，不强制深色，不删除用户文件 |
| 工作区旧覆盖 | 统一继承 Default，不覆盖 app 的明暗偏好 |
| 内置与设置目录 | 只有 Default，不残留可选择的其他预设 |
| 首屏、加载失败、运行时编译 | Default 同一模式下的语义色完全一致，无固定 50% 混色 |
| 合格原色 | 文字颜色尽量保留原色，不能无理由变脏 |
| 不合格原色 | 按需修正文字色，原始填充与图标色不变 |
| 常用背景与浅色状态底 | 正文及语义文字达到 4.5:1，实底上的文字按各自底色选择 |
| 现代 CSS 与错误输入 | 保留编译器校验、诊断、回退和取消机制 |
| 多窗口 / OS 模式 / 字体 | 持久化与同步不受主题目录收敛影响 |
| Run / 轨迹 / 内容 | 保持已批准的分类色，用户内容不被主题重染 |

验证入口：`scripts/verification/default-theme-refinement-workflow.ts`，及已有 theme-contract / theme-startup / theme-browser-host / Run 工作流。使用真实 CSS、ThemeProvider、编译器和设置组件，桥接与账号数据隔离；不替代打包客户端或物理平台验收。

验证隔离要求：工作流间不共享 Vite optimizer 缓存；启动读取用可释放的 gate 而非固定睡眠；取证输出不应再次充当下一次测试的源代码输入。真实源码仍须记录 hash，bundle、截图和测试 profile 由独立产物 hash 覆盖。

## 设计与取证入口

本轮基于已批准的 [Run 演示](../prototypes/run-redesign-2026-10-23/README.md)、[实施记录](run-view-redesign-2026-10-23.md)和[审视记录](run-view-review-2026-10-23.md)。

## 实施结果

- 产品主题目录和外观选择仅保留 Default，移除 Geek、Cyberpunk 2077、Ink 的三份源码及三份打包资源。旧 app 选择统一解析为 Default，工作区覆盖停用；明暗模式和字体保持独立，用户文件不删除、不覆盖。
- 默认原色、表面、边线和文字与批准的 Run 视觉协调。全局显式状态图标使用原色；文字使用对比度安全的文字色；实底使用各自的 on-color。修正过重的会话状态底，并将两处维护到的状态按钮接入 craft-control，验证键盘及 390px 触摸操作后退役两条旧例外。
- 固定 50% 混色取消。共享 policy 从原色开始，只有不足 4.5:1 时才按 1% 步长向 foreground 混合；测量八种承载面及同角色 20% 状态底。图形下限为 3:1，四种实底分别选择黑白文字。静态生成、启动/失败回退、浏览器编译和颜色门禁共用同一策略，策略版本进入 revision。
- 保留文件 schema、编译器验证、诊断及 snapshot/IPC 格式，用于内部校验与兼容；这些能力不增加可选择的产品主题。文档、生成契约和七份 locale 同步，删除四个失效翻译键。
