# 本轮存量治理：修复前失败场景与验收

Status: accepted — 用户于 2026-10-16 确认整体实施计划；本矩阵先于产品修改编写。

对应[整体计划](../process/project-governance-audit-plan-2026-10-16.md)。所有持久化、删除、服务及浏览器数据均为隔离夹具。

| 场景 | 修复前失败条件 | 必须保留/恢复的结果 | 验证入口 |
| --- | --- | --- | --- |
| H01 | 头大于 8 KiB，含 description 或 transfer summary | 保存、同步/异步读取、列表、完整重载均可见，内容不截短 | 真实 JSONL 与会话存储 |
| H02 | 首行在 8 KiB 边界两侧；中文横跨块边界；末尾无换行 | 返回同一合法头，消息不被当作头读取 | 真实文件 |
| H03 | 损坏首行、目录代替文件、文件不存在 | 继续按原语义返回 null；已打开句柄关闭 | 真实文件/目录 |
| D01 | Windows 非共享删除句柄锁住会话文件 | 删除拒绝；内存索引仍保留；不发成功事件；解锁后可重试 | 真实 SessionManager + 文件锁 |
| D02 | 删除时有已启动写入或待防抖快照 | 等待已有写入收尾，取消待写快照，成功后不复活目录 | 真实持久化队列 + SessionManager |
| D03 | 重复删除、正常删除、清理执行资源 | 不重复通知不存在会话；执行资源仍按现有流程释放 | SessionManager |
| U01 | 相同 usageId 重放相同/不同内容 | 相同内容只保留一条；不同内容拒绝，事务中新事实不残留 | 真实文件 SQLite/WAL |
| U02 | 0/1k/10k/50k 历史，每次新增用量全表解析 | 新增与单条重放不枚举历史；记录相同条件的前后中位数 | 生产 commitFactsAndUsage |
| S01 | 两个客户端在同/不同工作区并发检索 | 双方都得到完整结果，同一客户端的新查询仍可取消旧查询 | 真实 WS/RPC + ripgrep |
| S02 | 文本含 base64；附件含编码噪声；混合文本/图片 | 普通文本仍可搜；二进制噪声不产生结果；片段和计数一致 | 真实 ripgrep/JSONL |
| S03 | 断开连接、搜索完成、无结果、隐藏会话 | 子进程/归属及时清理，保持既有返回格式和隐藏规则 | 真实 WS/RPC |
| M01 | HTTP 自定义头、Authorization、URL 更新 | 下一次调用使用新配置；无变化、头名称大小写/顺序变化不重连 | 本地真实 HTTP MCP |
| M02 | 调用方原地修改配置对象；stdio 参数/env/cwd 变化 | 已连接配置不被外部对象污染；stdio 先复现再实施 | 真实 HTTP/stdio MCP |
| V01 | A 请求慢于 B；旧 404 晚于新成功 | 地址和内容属于 B；旧错误和 finally 不覆盖当前状态 | 生产 Viewer + 浏览器 |
| V02 | 请求未完成时清空、回上传页、卸载 | 旧请求不能恢复已清空会话，无未处理异常 | 生产 Viewer + 浏览器 |
| W01 | lazy App chunk 加载失败、子组件渲染异常 | 出现已有错误提示与重载按钮；恢复网络后重载正常 | 生产 WebUI + 浏览器 |
| T01 | 用量、输入脱敏、项目记忆旧断言 | 验证当前已接受契约，仍能检出字段错误、错误泄露和记忆丢失 | 现有测试 + 原生验收 |
| T02 | CDP/窗口 mock 缺少现有平台方法/事件格式 | mock 能执行真实调用路径，原断言保持有效 | 现有隔离测试 + Electron/CDP |
| T03 | 真实构建和 30 次 Argon2 登录超出单测默认预算 | 用测量决定场景预算；保留真实构建与 30 次成功断言，清理不与请求竞跑 | 现有测试串行及全量运行 |
| T04 | 无全局 uv，但打包 uv 已准备 | 文档工具测试使用已有运行时，24 项仍执行 | 原有 test:doc-tools |

不通过跳过、删断言、降低 Argon2 参数、放宽认证/限流规则或吞错使检查通过。测试变更先于相应产品修复；端到端流程输出源码身份、命令、退出码和可复核 JSON/媒体。
