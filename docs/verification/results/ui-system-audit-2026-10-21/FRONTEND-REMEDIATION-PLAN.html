00 / Self-review

我自己先修正了五个判断，并重排了顺序

计划最怕“看起来都对，顺序是错的”。重新审视后，有五个地方必须先说清楚， 否则 R0–R2 会在执行中变形。

CORRECTION 01

34px 冲突是真的，但不是截图的主因

你指出的 min-height 冲突成立：xs/compact 被钉在 34px，22/26px 是死档位。 但当前生产 0 个 xs/compact 调用，所以它不是“界面变糙”的直接原因； 它是契约级缺陷，会阻塞任何新紧凑控件。

CORRECTION 02

82 个丢层点不等于 82 个同等严重

可见影响集中在 Button、Badge、MetadataBadge、Tab、Artifact 状态章、Task 标题 六个原语。计划先修这六个，而不是逐页打补丁；其余点跟着原语一起消失。

CORRECTION 03

R3 不能放到最后

没有计算样式和对比度门禁，R0–R2 会在下一次 UI 迁移中回退。 R3 的最小集必须和 R0 同一个 PR；完整债务 burn-down 可以后置。

CORRECTION 04

50% 封顶会伤害宽 diff

封顶只作用于“伴随模式”：默认折叠空工作台，保留手动拖宽和全宽展开。 不是把工作台锁死，而是不让一个空面板占掉半屏。

CORRECTION 05

中性看板不是去色

列身份保留 2px 色条/圆点，语义交给状态章；去掉的是整列 tint 和实心大色块。 看板仍然有颜色，只是颜色不再互相打架。

ORDER

顺序按依赖，不按严重度

先 merge、再控件高度、再 chrome、再布局/看板，最后门禁。 如果先改看板颜色，下一次 UI 迁移会把修复重新冲掉。

!

结论：计划成立，但要先承认两件事——最响的视觉问题（字号/文字色）来自合并层，不是看板；最容易被忽略的（34px）是契约问题，不是当前主因。 所以 R0 必须先落地，R2 才有意义。

03 / Findings

两个 P0，八个 P1，按依赖修

P0 是“不修就会继续继承错误”的原语；P1 是发布前应修的全局观感与可用性。 P2/P3 放在折叠区，避免噪声。

P0-1

字号在 cn() 里被吞掉，填充型小按钮文字直接消失

82 sites 15px ≠ 13px 35 buttons

text-meta / text-body 被 tailwind-merge 当成 text-color，和 text-foreground / text-background 二选一。Badge、筛选、tab 变 15px； 小填充按钮丢 text-background，浅色主题下文字继承前景色，直接不可读。

证据

utils.ts:4-6 · button.tsx:7,54 · badge.tsx:33；真实 merge 输出已复现。

影响

  • 层级随机：15 / 12 / 11 混排
  • 下属元素比上级大
  • 小按钮文字不可见

修复

扩展 twMerge，把 7 个 tier 注册进 font-size；加计算样式契约。

P0-2

xs / compact 的 22 / 26px 是死档位，被 34px min-height 覆盖

0 production calls 34 / 34 contract 22 / 26

CSS 只映射了 sm/lg；xs/compact 落回 34px。计算样式实测 xs=34、compact=34。 当前生产没有调用，所以它是契约级缺陷，不是截图粗糙的直接原因；但任何人下次使用都会踩坑。

证据

roles.css:79-82；button.tsx:24-26；control-measurements.json。

影响

  • 两个 size tier 名义存在、实际不可用
  • 控件高度契约不可信
  • 新紧凑控件一用就错

修复

补齐 data-control-size 映射；height = min-height；加高度契约。

Files 工作台：三条 37.5px 横条，四种选择语法

  • 空状态下尤其明显

聊天 flexBasis 固定 600、MAX=600；工作台拿剩余空间且无上限。 1920px 下，空 Artifacts 面板 961px，聊天 606px；隐藏导航时工作台可达 68.1%。

P1-4

表面语言爆炸：12 种背景 alpha、9 种边框 alpha、15 种圆角、19 种阴影

12 alphas 22 border+shadow 537 vs 670

每处只差 1–2%，叠在一起就是“说不出哪里不对”。shadow-minimal 自带 1px ring， 又叠 border 形成双层边；二级文本同时存在 muted-foreground 与 text-secondary。

  • 卡片像俄罗斯套盒
