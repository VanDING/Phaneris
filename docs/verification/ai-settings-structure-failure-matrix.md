# AI 设置结构实施：先列失败场景

2026-10-05，在修改产品代码前列出。范围为用户确认的“连接 → 会话 → 高级”；高级内图像、决策、缓存与运行优化各自独立折叠。候选 Default 不在本次应用范围内。

| 失败场景 | 验证结果必须满足 |
| --- | --- |
| 页面仍残留原来的并列分区或内部分页 | 一级分区只有连接、会话、高级，顺序固定；无 tablist |
| 三个高级项互斥展开或存在重复的内层配置折叠 | 默认均收起，保留状态；可同时打开，关闭一个不影响另两个；键盘可操作 |
| 上下文选择仍在会话之外或使用不同控件 | 会话中使用标准右侧菜单；三种策略保存正确，失败恢复原值 |
| 完全继承的工作区重复展示有效值和编辑卡片 | AI 页只显示当前工作区入口，不列其他工作区；编辑归工作区页 |
| 工作区选择不同连接后保留不兼容模型 | 一次连接写入即可清除不兼容模型；界面与实际生效值一致 |
| 全局会话更改清除工作区例外 | 已有例外保持，逐项恢复继承后使用新的全局值 |
| 工作区写入失败、加载失败或切换时出现旧结果 | 写入失败恢复显示；加载错误可重试；工作区切换隔离异步结果 |
| 只有 ChatGPT 订阅连接仍出现空 Automatic 下拉和错误警告 | 图像摘要显示未配置；展开给兼容 API 连接引导，解释图像理解与生成区别 |
| 图像配置入口仍可以误选订阅或不兼容供应商 | 定向 API 密钥流程仅显示 OpenAI / OpenRouter；普通添加连接保持原流程 |
| 多账号自动选择或显式账号失效时偷换账号 | 显示实际自动选择；失效／删除显式账号保留选择并给修复操作 |
| 切换图像账号保留另一供应商模型或保存失败丢失选择 | 账号变化清除模型；失败保留之前设置并显示可读错误 |
| 图像已配置但状态请求失败却显示为未配置 | 失败状态明确可重试，不把传输失败视为未配置 |
| 决策服务配置被二次折叠、关闭时无法预先配置 | 单层展开直接提供服务、凭据、模型和功能；关闭时仍可准备配置 |
| Guarded 在 AI 页重复一级分区或权限入口定位失效 | 模式入口留在权限页；配置只打开高级中的决策项，其他项维持关闭 |
| 决策服务请求失败隐藏整项或永远加载 | 折叠摘要与展开错误可见，提供重试；Guarded 不被标记可用 |
| 连接身份、能力或用途错误 | 订阅／API 密钥明确；不显示后台实现名；部分模型的图像理解不等于全连接支持；用途标签准确 |
| 重命名、验证、编辑、删除或普通接入流程受重排影响 | 原有操作继续可用，验证失败保留，OAuth 不被图像流程过滤影响 |
| 折叠后缓存、RTK 或决策配置丢失 | 已保存的开关在再展开时一致；失败回滚；RTK 诊断仍可达 |
| 中文或窄窗口溢出、控件前后不一致 | 全部使用公共设置行，右侧操作；浅色、深色、中文窄窗口截图无溢出和缺失翻译 |
| 本次意外应用主题、修改个人配置或扩大为打包／发布 | E2E 使用内存传输与隔离目录；候选主题和内置主题保持；不打包、不发布 |

验证采用实际 React 页面和公共接入组件的浏览器 E2E，保存 JSON 记录与截图；模型、账号和工作区为测试数据，不调用真实付费服务。
