# API 接入修订：失败场景与验收

| 场景 | 必须满足的行为 |
| --- | --- |
| 接入方式前进、返回、连续切换 | 当前步骤立即接管；没有两层文字叠加、淡出空白或退出步骤抢占焦点 |
| 选择普通 provider | 仅需 provider 和 API Key；不等待前端模型目录，不显示模型或辅助模型选项 |
| 选择 Custom | 仅要求地址、协议和适用的凭据；没有预填的其他供应商模型 |
| Custom 未填模型 | 在连接测试之前发现模型，实际请求使用发现到的模型；保存同一个默认模型 |
| 端点无法列模型或返回空列表 | 提供明确错误与可选的手动模型回退；不发送猜测的模型或保存不可用连接 |
| 端点鉴权失败 | 显示鉴权错误，保留输入，不保存连接 |
| 更新凭据 | 保留现有默认模型、辅助模型和目录，包括不在 SDK 目录中的模型 |
| 切换 provider 或 Custom 地址/协议 | 不携带前一 provider 或端点的目录与模型选择 |
| 原生 provider 模型自动化 | 由后端使用该 provider 的目录与默认值，不能选中其他 provider 的模型 |
| 系统设置修改辅助模型 | 按连接保存；影响标题、摘要和 call_llm；恢复“自动”能清除显式值 |
| 设置保存失败 | 保留原值、显示错误，可以重试；不能显示虚假成功 |
| SDK 的 pi/ 模型前缀 | 默认模型和辅助模型的 ID 规范一致，刷新后显式选择仍有效 |
| OpenCode / 自定义网关使用 DeepSeek | 连接图标表示服务商或端点，不从模型品牌猜连接品牌 |
| 中英文、深浅主题、窄屏 | 控件可用、无横向溢出；简体中文无新增英文说明 |
| 决策选项不可用 | 核对退役标记、执行入口及提交记录；区分产品退役与 provider 能力，不擅自重新启用 |
| 百分比压缩阈值 | 按当前模型上下文窗口计算，切换模型重新计算；仍保留 SDK 安全预留 |
| 已保存 token 阈值 | 老配置仍生效，界面标明旧值；选择百分比后迁移，恢复默认清除覆盖 |
| 图像兼容端点 | 必须为 OpenAI Images API，不把聊天兼容自动等同于图像能力；显式选择端点与图像模型 |
| 兼容图像调用 | 请求使用 images/generations、指定模型和 base64 输出；错误保留，不偷偷切换服务商或重复付费调用 |
| Custom 输出上限未报告 | 不继承其他 provider 同名模型的 maxTokens；使用保守预算，不能按上下文窗口推算输出上限 |
| Custom 输出上限已报告 | 使用端点返回的 max_output_tokens / max_tokens 等字段；实时目录覆盖旧缓存里错误的输出上限 |
| 全部费用未知 | 显示“未知”，不能将求和起始值 0 当作真实免费用量 |
| 已报告费用为零 | 显示真实 $0；已知零费用和未知请求混合时，显示已知小计并保留未知提示 |
| 已知收费与未知请求混合 | 展示已知费用小计与未知覆盖范围，不修改原始用量记录 |
| 原生图像模型能力过时 | 不再推荐已关闭的 gpt-image-1；不在客户端拦截官方已支持预览的 gpt-image-2 透明输出 |

验证使用隔离配置、合成密钥与本地模型端点。产物应包括 JSON 断言结果、浏览器 trace 与截图，明确未覆盖真实付费 provider 的范围。
