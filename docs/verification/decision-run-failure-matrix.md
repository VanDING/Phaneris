# 会话决策专项：实现前失败矩阵

2026-10-09。对应 [设计方案](../design/decision-assistance-run-plan.md)。本矩阵先于产品实现；端到端验收需产出可重放脚本、JSON 结果、事件／用量关联与截图。

| 场景 | 失败方式 | 必须验证 |
| --- | --- | --- |
| 配置页 | 仍读取统计或依赖统计服务 | AI 无累计统计请求；配置和连接测试独立工作 |
| 权限页 | 删除中转区块时破坏模式 | Guarded 模式、选择器和保护逻辑保留 |
| 会话范围 | 全局日志被当成会话记录 | A/B、工作区与服务器隔离 |
| 固定会话 | 跟随当前聊天错误切换 | 固定 A 后切 B 仍显示 A |
| 异步查询 | 旧响应覆盖新范围 | 请求代次与取消隔离 |
| 空消息 | 整个 Run 提前返回 | 无聊天消息仍可访问 Decisions |
| 前置失败 | 无配置时静默消失 | 已触发的判断留下不可用记录，供应商调用为零 |
| 功能关闭 | 每条消息制造噪音 | 关闭路径不新增判断；旧记录仍可读 |
| 批次 | 一件判断被计为多件 | 同一决策点多次请求归一事项 |
| 重试／重放 | 费用或事项重复 | 请求／事件身份幂等；费用只来自原账本 |
| 模型建议 | 推荐被当成生效 | 推荐、应用、观察分开 |
| 过期结果 | 新轮次／用户编辑后仍统计调整 | 记录丢弃，不增加实际调整 |
| 后续观察 | 访问尝试被当成成功／准确率 | 明确观察／推断，保留事实语义 |
| 取消 | 被当成供应商失败 | 取消独立状态；已发生费用保留 |
| 超时／无效答案 | 误放行或错误声称完成 | 原回退策略保持，实际处理可追溯 |
| 崩溃／重启 | 记录丢失或触发自动请求 | 持久记录可重读；查询不调用模型 |
| 未知费用 | 显示为免费／零 | 全未知显示未知；混合显示已知部分和未知数量 |
| 上下文 | 辅助 Token 进入窗口占用 | 只计消费，不污染主模型上下文 |
| 总费用 | 再加 Decision 开销 | 分解项与账本／会话总量一致 |
| 历史 | 拼接时间相近的记录 | 缺关联明确降级，不猜轮次或费用关系 |
| 分页 | 第一页被当总量 | 同一完整快照上的总量与分页 |
| 实时事件 | 只有用量通知，没有动作通知 | 应用与后续观察更新；重连重查 |
| 旧服务器 | 回退展示全局数据 | 明确能力不支持 |
| 无会话自动化 | 被挂到当前聊天 | 仅自动化历史／诊断归属 |
| 归档／分支 | 重复消费或历史不可读 | 归档可读，分支不复制消费 |
| 删除 | 晚到事件复活会话 | 删除新增明细，撤销查询，忽略晚到事件 |
| 隐私 | provider 错误回显输入 | 只存脱敏摘要与结构化事实 |
| 窄面板／键盘 | 溢出、失焦 | 标签导航、筛选与详情返回可操作 |

覆盖全部 13 个功能；每项需检验响应、回退和处理确认。特别检验轮次结果／语义标签的晚到丢弃，决策工具下游采用未知，大结果与标签的批次归属，以及 Guarded 的人工确认保护。
