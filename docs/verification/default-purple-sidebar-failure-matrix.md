# Default 紫色与 New Session 验收条件

2026-10-05。以下条件在产品修改前列出；本轮仅恢复原有 Default 强调色，并调整 New Session 表面。

| 失败条件 | 验证 |
| --- | --- |
| 恢复了近似紫色，或仅恢复浅色 | 使用原有精确值：浅色 `oklch(0.488 0.275 280.3)`、深色 `oklch(0.626 0.221 291.7)`；实际页面比较 accent 与 ring 的计算色 |
| canonical、内置 JSON、预览参考与默认 CSS 漂移 | 走主题加载器，比较两种模式全部主题引擎 token，校验资源相等 |
| 恢复紫色时改变了已确认的表面和消息气泡 | 与上一轮资源比较，仅允许 accent/ring 不同；真实消息保持灰白/中性深灰，正常正文、辅助文字与消息对比度 ≥4.5:1 |
| 将全局 secondary 改白，损害其他控件选中态 | 保留现有 secondary；仅调整 New Session 按钮使用 card/cardForeground |
| New Session 仍发灰，或悬停透出侧栏材质 | 实际客户端静止与悬停均与设置卡片同色；浅色纯白、深色卡片色；悬停保留阴影反馈 |
| 文字、图标不清晰，按钮键盘操作失效 | 对比实际按钮与卡片文字色；键盘聚焦可见、Space 可打开新会话；保存明暗截图 |
| 构建或包内仍残留上一版配色 | 全量 Electron 构建，启动新包验证主题；包内资源与源码匹配；DMG/ZIP 校验及只读挂载 |

原有紫色在石墨深色背景上的聚焦环对比度为 4.52:1，在深色卡片上为 4.24:1。按用户要求保持原色；品牌色与图形检查要求 ≥3:1，独立记录测量，不将它们计入常规正文 ≥4.5:1 的结论。

所有客户端验收使用临时配置目录和示例账户，不修改个人主题或配置。
