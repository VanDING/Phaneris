# 前端外壳视觉微调：失败矩阵

状态：实施前定义。范围为当前 W1–W5 分支的可见外壳，不改变主题字段含义、用户配置或阅读列宽。

| 场景 | 可能失败 | 验收 |
| --- | --- | --- |
| 首行 | 只移除顶边距，按钮与标题的中心仍错位 | 真实 Electron 新建按钮、列表标题、会话标题同顶线，中心偏差 ≤1px |
| 展开侧栏 | 缩小字号掩盖密度问题；保留 40px 固定行高 | 默认宽 200px、普通行 28px、图标 16px；中文标签保留字号 |
| 收起栏 | 按钮成 24×36 长方形；缩小后留白太局促 | 鼠标栏宽 48px、按钮 24px 正方形、两侧各 12px、行间距 8px；展开则为 28px 行、2px 间距和文字内容边；首行中心仍与标题对齐，设置与头像可操作 |
| 已保存宽度 | 修改默认值清掉用户拖拽结果；新接缝位置造成按下后跳宽 | 已保存 256px 宽度刷新后保留；展开/收起时，拖拽增量与面板宽度增量一致，刷新仍保留 |
| 拖拽边界语义 | 修改已有 sash 节点后继续依赖静态交互豁免，键盘无法调整宽度 | sash 使用带名称、方向与当前值的宽度滑块语义；方向键调整 16px，Home/End 使用现有限值，焦点可辨且宽度持久化 |
| 滚动 | 滚动条使左/右内距不同，底部项无法访问 | 侧栏为对称内容边；短窗口仍可滚动到最后一个导航项 |
| 侧栏接缝 | 6px paper 间隙叠到较窄图标栏，导致整条可见灰带偏宽、图标看起来偏左 | 侧栏↔列表间隙为 0，列表↔内容保留 6px；按可见灰带（含边界）验图标中心，sash 与拖拽坐标使用相同几何 |
| 面板边界 | 只修阴影别名，偏蓝边框与过弱阴影仍存在 | Default light 中性边框，navigator/content 有可见软阴影；暗色保留自己的材质 |
| macOS 圆角 | 主题 6px 覆盖宿主策略；过大的底角被窗口裁切 | Default 内角 10px，贴窗口底角 8px；紧凑模式底角保持 0 |
| Windows 圆角 | 把 macOS 圆角无条件用于 Windows | Windows Default 保留 6px；本机模拟平台策略与真实 Windows 验收明确区分 |
| 自定义主题 | 产品微调吞掉主题 radius/depth | Ink、Geek、Cyberpunk 的圆角和阴影继续由主题控制，切回 Default 恢复宿主策略 |
| 放大文字 | 固定小行高裁字、按钮越过标题栏 | 原生 200% 缩放与更大根字号无横向溢出，导航与首行可扩展 |
| 触摸 | 鼠标密度覆盖 44px 触摸目标 | coarse pointer 恢复 ≥44px 控件与足够宽的图标栏 |
| 操作反馈 | 更紧凑的 overflow 裁焦点环或 Tooltip | 键盘焦点可辨、收起 Tooltip 可见，头像/设置浮层正常 |
| 启动 | 先显示缓存/Default 的大字号，再应用持久主题的小字号 | 旧缓存与真实持久主题不一致、偏好 RPC 延迟超过启动动画最短时长时，所有可见外壳帧使用最终字号；字体就绪后才揭开启动层 |
| 启动失败 | 等待主题/字体使启动层永久阻挡界面 | 偏好读取失败或主题失败能揭开可用快照/Default 回退；没有 API 的预览入口仍正常 |

验证入口：`bun run test:shell-visual`。使用实际 Electron main/preload/renderer、临时配置和本地会话；保存截图、几何/样式 JSON、构建哈希与可校验 manifest。可用 `PHANERIS_VISUAL_BASELINE=1` 记录实施前观察值，基线模式不宣布目标已通过。
