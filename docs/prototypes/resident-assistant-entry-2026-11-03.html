为什么是像素

顶部的助理不该是一行工具。像素岛先以节奏存在：它看得见、会变化、能瞥一眼；只有点击，才进入工作深度。

先瞥一眼，再决定

指针停留 120ms 才展开快照，移开就收起。用户不需要先承诺一次点击，也不会因为鼠标路过被弹窗打断。

像素是状态，不是装饰

格子只在 hover 与活动时加快、变亮；静止时保持低亮度，不做持续闪烁。琥珀色只留给“待确认”，不抢紫色的身份。

对话保持纯

进入对话后没有侧栏、没有任务卡片，只有 thread 和 composer。任务进度、分派和交付物都退到右上角「更多」。

代价要明说

触控没有 hover，点击会直接进对话；键盘 focus 可以展开快照。像素岛只占顶栏 40px 高度，但持续 Canvas 有成本，宽度、亮度和动效都必须克制。

实现落点

像素岛嵌在顶栏内，不改变顶栏高度。快照是它下方的一张轻纸卡片；打开对话时，surface 从像素岛的实际矩形裁剪到全屏。

像素岛AssistantIsland 360×40，嵌在 48px 顶栏内；Canvas 2D 的 72×8 个 4×4 方格，按波、扫描和稀疏闪烁变化。
主题浅色 / 深色切换同时作用于页面、像素配色、文字和边框；header 图标与 stage 分段开关双向同步。
快照IslandPeek 120ms hover intent + 180ms 展开；移出 180ms 收起。focus 同样展开；快照是下方轻纸浮窗，不改变顶栏高度。
对话AssistantSurface 复用常驻 Session 的 thread 与 composer；没有侧栏和卡片；打开时从像素岛矩形展开，焦点进 composer。
更多右上角 TaskPopover 显示进展、分派、交付物；点击外部或 Esc 关闭；不改变对话布局。
降级键盘 focus 展开快照，触控点击直接进对话；prefers-reduced-motion 静止像素网格；慢放只做审阅。
