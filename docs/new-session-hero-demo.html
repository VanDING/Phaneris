这个页面在说什么

  • 只有两样东西：品牌符号（仓库里已有的 components/icons/PhanerisSymbol.tsx，不是新画的）和 一句 slogan。
  • 为什么去掉字标：产品名已经出现在侧栏、启动屏、窗口标题和「关于」里，空会话页再写一遍是重复。去掉之后整块读作「一个符号 + 一句题词」，比三行更干净。
  • 去掉字标后 slogan 是唯一的文字，所以字号从 15px 提到 17px，与符号的距离收到 22px，整块重心不会散。
  • 只用 --foreground 与 --muted-foreground 两个颜色，无描边、无背景、无图形。

动效：一次落笔，之后只剩呼吸

  • 画（0 → 2.1s）：符号的五块多边形用 stroke-dashoffset 从左到右画出来，视口高 DPI 下是 1.6px 描边。
  • 上墨（1.15 → 2.55s）：描边快画满时填色淡入，所以是「先勾线、后落墨」，不是缩放或淡入。
  • 题词（1.7 → 2.8s）：slogan 等符号画完后上浮 7px 淡入——先有形，后有话。
  • 呼吸（3.2s 起，12s 一轮，无限）：符号缩放 ±1.2%、slogan 透明度 1 → 0.8 → 1。两者同频同相，整块像在缓慢换气。
  • 用工具栏的「动效 · 关」可以看到静止状态，其实也就是 prefers-reduced-motion 下所有人看到的样子；「开（重播）」会从头再跑一遍。
  • 三点克制：没有 hover 动效（hero 不可点）、没有循环的线性位移动画、不用 JS 驱动（纯 CSS，不占用主线程，流式输出时也不会跟着重渲）。

刻意没有做的事

  • 没有字标、没有刻度环、没有配置读数、没有路径胶囊——按定稿意见全部砍掉。空会话的页面不需要汇报状态，输入框里的「工作目录 / 数据源」按钮已经在说这件事了。
  • 没有卡片墙：4 个圆角示例卡片 + 标签 + → 是这一版 AI 界面的通货膨胀品，对专家用户是噪音。
  • 没有渐变球 / 光晕 / 玻璃：一个符号加一句话，深浅两套主题各自成立。
  • 没有逐字/逐词弹出、没有视差、没有跟随鼠标的光标特效：那类动效会把注意力从输入框拉走。
  • 输入框不动：仍留在底部、仍是唯一主操作，因此发送首条消息时没有布局跳动。

定稿记录与一处需要你知道的风险

  • 结构：只保留品牌符号 + slogan（用户定稿，已去掉字标）。
  • 英文：Let it exist, let it go.　中文：山间何事，松花酿酒，春水煎茶。
  • 出现范围：每次空会话都出现（用户定稿）。
  • 需要留意：中英两句现在不是同一个意思——中文是闲居山中的自况，产品其实是本地执行的 Agent 工作台，两者没有语义对应。作为「品牌气质的题词」成立，作为「同一句话的翻译」不成立。如果介意，可以把中文界面的 slogan 也固定成英文原句。

已确认的实施位置（勘察完成，尚未动手）

  • 落点：ChatDisplay.tsx 里消息区（1521）与输入区（1971）之间，作为兄弟节点插入；用 absolute inset-0 铺满空白区，输入框一行都不用改。
  • 门槛必须三个条件都满足：!compactMode && !messagesLoading && !messagesLoadError && messages.length === 0，否则切换会话时会闪一下 hero。
  • 坑：不能放进 ScrollArea 内部（它的内容层是 display:table，h-full 撑不开），也不能放进消息区的遮罩层（上下 32px 会把边缘淡掉）。
  • 品牌符号直接复用 PhanerisSymbol.tsx，不再需要 wordmark 组件。
  • 文案成本：slogan 要同时补进 7 个语言文件（parity + sorted + coverage 三个门禁）。
