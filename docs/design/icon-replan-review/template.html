状态也要对照

文件、运行轨迹、终端在工作台收起后保留后台圆点；重新点击会激活已有标签。浏览器使用独立的存在状态；帮助菜单包含七个文档入口。

当前源码中，顶栏不同状态还会使用不同描边粗细。L1 保留这种机制；P1 与 R1 使用原生图形，通过前景、背景与圆点区分状态。

工作台右上角也已补充固定／取消固定、放大／还原、收起与关闭。可在工作台直接操作。

文件名优先，扩展名兜底

Markdown、JSON、TypeScript、React、图片、PDF、Word、Excel，以及 Git、Docker、ESLint 配置分别识别。目录和未知类型保持中性；文件状态颜色不混入类型图标。

本轮的边界

  • UI 图标选 P1／L1／R1，都可以搭配这套文件主题。
  • 文件夹、打开／关闭箭头、复制与下载等操作按钮继续使用所选 UI 图标。
  • 浅色与深色分别配色，文件名文字保持正常前景色。
  • 这版 Seti 没有 Bun 专用字形：bun.lock 用锁文件回退，bunfig.toml 用配置回退，不伪造 Bun 标志。

范围还包括文件面板、附件、产物卡片、预览标题和文件搜索结果；类型图标应由同一个解析器输出。

新的规划：两项决定，三条 UI 路线

先选界面图标路线，再独立决定是否使用彩色文件主题；两项均可在本页组合比较。

路线保留本轮变化实施影响
P1 · 柔和轻线Phosphor Light 的轻盈感圆气泡、灯泡、滑杆、循环弧线等；保留必要的语义角度仍是完整换库，需要覆盖共享 UI 与所有端
L1 · Lucide 精选现有库、描边机制与大多数图标只换主要导航及少量功能图形，保留现有圆角新建与侧栏按钮改动范围最小，主题描边与接口可继续使用
R1 · Remix 线性统一线性操作、现有配色与状态机制重新选圆气泡、灯泡、拼图和循环；不采用面性导航完整换库；原始路径重量仍需按尺寸校准
彩色文件主题目录、未知类型、操作按钮保持中性Seti 类型字形、文件名优先规则、深浅色配置独立公共解析器，扩展到附件、文件卡片和预览

确认后才进入实施

  1. 冻结主要导航、顶栏与文件类型规则。
  2. 建立语义图标入口与公共文件类型解析器。
  3. L1 按选定项替换；P1／R1 按区域迁移，并解耦 LucideIcon 类型。
  4. 统一桌面、WebUI、查看器和共享 UI。
  5. 验证真实 14／16／18／20 px、深浅色、工具栏全部状态与文件回退规则。

继续保留

Phaneris 标识、MCP、服务商与消息平台标志、用户自定义图标、六种任务状态及加载动画的业务含义。

取舍提醒

灯泡强调能力与想法，弱化原闪电的速度含义；循环弧线可能使自动化偏向“重复运行”，并不覆盖所有事件触发语义。图形变柔和与语义清楚需要一起判断。

原始范围盘点为 237 个生产导入文件、197 个去除别名后的 Lucide 组件。L1 实施不需要替换全部组件；P1／R1 也不包含品牌和用户资产。

官方来源：Phosphor、Lucide、Remix Icon、Seti。本页离线可用，没有改动应用源码与依赖。

本轮仅重新规划与演示。顶部入口、文件识别与状态交互均为模拟；所有图形和文件字体已内嵌。
