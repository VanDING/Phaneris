实施时要一起处理的约束

  • 增加统一的语义图标入口，再按区域迁移；LucideIcon 类型也要改为库无关接口。
  • Phosphor 原生支持 Thin、Light、Regular、Bold、Fill、Duotone 六种 weight。本轮使用三种，按原始 256×256 网格缩放；应使用 weight 校准重量，不直接套用现有 --icon-stroke-width。
  • 补查颜色继承、禁用态、加载旋转、按钮热区、SVG 选择器和无障碍名称。
  • 工作区落盘的状态图标不能随库替换被覆盖；既有自定义图标仍应生效。
  • 同步修改依赖 .lucide-* 类名的验证脚本，再验证桌面、WebUI 与查看器。

本轮候选

P1 用 Light 与简洁隐喻，P2 用 Regular 与常规隐喻，P3 用 Duotone 及部分更具象的形状。基础操作始终保留清楚的轮廓。Duotone 的淡底沿用原始 SVG 的 20% 透明层，继承同一个前景色，未额外引入彩色。

资产来源

本演示固定使用官方 @phosphor-icons/core 2.1.1 的原始 SVG。图标名称与 weight 可在「图标对照」查看。来源与 React 用法见 官方 React 仓库，资源包遵循 MIT 协议。Phaneris 自有标识与用户图标保留。
