实施时要一起处理的约束

  • 增加统一的语义图标入口，再按区域迁移；LucideIcon 类型也要改为库无关接口。
  • Remix 的 Line 图标用填充路径绘出轮廓，不能直接沿用 Lucide 的 --icon-stroke-width 与圆头控制；需要重新校准 14–20 px 的视觉重量。
  • 补查颜色继承、禁用态、加载旋转、按钮热区、SVG 选择器和无障碍名称。
  • 工作区落盘的状态图标不能随库替换被覆盖；既有自定义图标仍应生效。
  • 同步修改依赖 .lucide-* 类名的验证脚本，再验证桌面、WebUI 与查看器。

候选边界

三套方案均来自同一个 Remix Icon 库，区别是语义造型、常态与选中态的用法。B 便于建立导航层级；A 更接近现有线性工作台；C 轮廓更醒目，但密集列表中的视觉重量较大。基础箭头、关闭、加减等操作在三套方案中保持线性。

资产来源

本演示固定使用 Remix Icon 4.9.1 的原始 SVG，使用名称可在「图标对照」查看。来源与 React 用法见 官方仓库；当前协议为 Remix Icon License v1.0，应按其条款使用；Phaneris 自有标识不参与替换。
