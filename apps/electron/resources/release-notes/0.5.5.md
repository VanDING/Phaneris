# Phaneris 0.5.5

This release closes the 0.5.x stability work with reliable AI connection validation, responsive startup, session-local execution and safer runtime maintenance.

## Improvements

- **Responsive startup** — Run full database integrity checks outside the main thread and show a lightweight loading window while workspaces initialize. Keep full verification and corrupt-database recovery before chat becomes available.
- **Background maintenance** — Prepare scheduled backups after workspace initialization and run backup and maintenance work in a worker, with cancellation and shutdown drainage.

## Bug Fixes

- **AI connection validation** — Give disposable Pi probes an existing temporary working directory, fixing Bun ENOENT when adding a provider. Keep real subprocess validation and release the process, temporary credentials and directory on completion or timeout.
- **Session working directories** — Run relative file operations, shell commands and permission checks from the resolved session directory, while preserving explicit project directories and stored legacy paths.
- **Safe daily backups** — Publish completed snapshots atomically, refuse accidental overwrites, repair incomplete daily backups and prune older snapshots only after successful publication.
- **Cancellation accounting** — Drain pending model preparation and observed results before clearing cancellation receipts, preserving known zero usage when a request never reached the provider.
- **Cache warming limits** — Preserve the explicit one-token output limit when a custom endpoint inherits options from an ordinary conversation request.
- **Stopped answers** — Preserve interrupted streaming text as intermediate content instead of presenting it as a final answer.
- **Compaction settings** — Reject non-finite token thresholds before JSON transport can silently treat them as the default setting.
