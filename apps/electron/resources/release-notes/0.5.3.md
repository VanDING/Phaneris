# Phaneris 0.5.3

This release makes local decision-provider authentication optional and removes unused runtime paths.

## Improvements

- **Decision providers** — Local and custom presets now show the API key field labeled “API key (optional)” instead of hiding it, so authenticated local servers can be configured from Settings.
- **Runtime cleanup** — Remove unused skill-mention UI, the duplicate network-interceptor entry point, and stale governance policy files.

## Bug Fixes

- **Session restore** — Share one restore path between cold persist and lazy reads, keeping queue recovery consistent for both.
