# Phaneris 0.5.2

This release improves conversation recovery and portability, makes Run context accounting more accurate, and fixes desktop startup and interrupted-conversation issues.

## Improvements

- **Conversation portability** — Copy session-owned files and Artifact working copies when branching. Include drafts and native conversation history in exports and workspace backups, and rebind imported files to their new location.
- **Run context accounting** — Separate content estimates from measured provider input, show unattributed input explicitly, and keep image payloads and message metadata from inflating text estimates.
- **Context inspection** — Show added, removed and modified entries separately, count images alongside text, and keep unchanged content estimates stable across requests.

## Bug Fixes

- **Conversation recovery** — Restore committed messages when the saved conversation snapshot is incomplete, while preserving existing message identities and avoiding duplicate entries.
- **Session updates** — Prevent concurrent message and metadata saves from overwriting newer changes. Preserve explicitly cleared values and edits made outside the app.
- **Drafts and Artifacts** — Keep private drafts, revisions and working copies with the correct conversation through restarts and transfers. Existing storage remains readable, with backups retained during migration.
- **Windows startup** — Fix connection handshake failures when browser UUID support is unavailable during startup.
- **Embedded previews** — Keep a failed embedded frame from reloading the entire app, ignore cancelled navigations, and bound page recovery retries.
- **Interrupted conversations** — Prevent unmatched tool results from causing repeated API errors when continuing after an interrupted response.
