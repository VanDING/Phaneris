# Phaneris 0.2.2

This release improves prompt safety, turn control, context reporting, and approval
recovery. The agent kernel uses Pi SDK 0.86.1.

## Safer prompt context

Working-directory details, repository instructions, and saved preferences are treated as
data and sanitized before they enter the system prompt. Control characters are removed,
closing tags are neutralized, attribute values are escaped, and credentials are removed
from repository URLs. Preferences are clearly marked so their contents do not compete
with the prompt's instructions.

## More reliable turns and context usage

- Messages sent while a turn is running now arrive together and in order at the next
  model boundary. Messages that arrive later stay queued for the following boundary
  instead of being dropped or delivered one per turn.
- The context indicator now uses Pi's context-occupancy and compaction data, separate
  from cumulative billing usage. It updates on message and turn boundaries, including
  after /compact. When no current count is available, it shows “Usage unknown.”

## Better repository context

The agent receives the repository root and parent, selected subdirectory, origin remote
(with credentials removed), default branch, and standing guidance. A changing Git
summary reports the branch, upstream, ahead/behind state, and worktree changes
separately to keep the cached system prefix stable. Only AGENTS.md and CLAUDE.md files
that apply to the selected directory are loaded, including on Windows. The system
prompt also explains how to work with automations.

## Fixes

- **Plan approvals are dispatched once.** Accept & Compact now uses one dispatcher and
  an atomic claim, preventing duplicate approvals during reloads or across windows. It
  waits for the session to become idle and compaction to finish.
- **Calendar dates follow the app language.** Month titles and weekday names now use the
  active locale, including English, Chinese, and Hungarian.
