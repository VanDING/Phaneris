# Phaneris 0.5.1

This release fixes internal reminder text appearing in conversation recommendations and improves context accounting and charts in Run.

## Improvements

- **Run charts** — Show per-request cache hit rates, keep long-history axis labels on one row, and use consistent colors across Overview, Context and Trajectory.

## Bug Fixes

- **Conversation recommendations** — Show concise skill and source suggestions in the interface language instead of internal system reminder tags, instructions and local paths.
- **Context accounting** — Keep estimated category tokens within recorded provider input so Context and Overview agree.
- **Package verification** — Check the single bundled Default theme when verifying packaged clients.
