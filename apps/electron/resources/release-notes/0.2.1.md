# Phaneris 0.2.1

A maintenance release focused on agent-runtime traceability, security updates, and
connection reliability. It upgrades the Pi SDK to 0.86.0 and the desktop stack to
Electron 44.4.3, React 19.3, jotai 3, and React-PDF 11 with PDF.js 6.

## Agent runtime

- Pi now gives providers a normalized transcript, so prompt and tool changes can be
  applied without rebuilding the cached prompt prefix. Trajectory snapshots continue
  to show exactly what the model received. Built-in file and shell tools request
  schema-constrained arguments where supported, and agent retry backoff is capped at
  60 seconds.
- Prompt-cache warming remains off. Its background refreshes would make billable
  provider requests outside the durable request ledger, leaving their cost unattributed.
- Extended prompt caching now uses Pi's cache-retention setting directly, so it applies
  to every SDK request path instead of only requests passing through the network
  interceptor.

## Request traceability

- Each dispatched request records its hash and byte count, plus an allowlist of response
  headers such as request IDs and rate-limit data. It never records request content,
  credentials, or arbitrary metadata. Evidence and usage are committed together.
- A read-only SDK observer records tool proposals and results, compaction, retries, and
  model or thinking-level changes during active runs. At run completion, Phaneris checks
  request outcomes against the usage ledger. The observer cannot block tools or change
  results.

## Security

This release closes 21 of 24 known dependency advisories. Three remaining advisories are
in the WhatsApp audio-metadata dependency stack and await an upstream release.

- Replaced abandoned xmldom 0.6.0 with the maintained @xmldom/xmldom package.
- Updated the document converter's SheetJS dependency from xlsx 0.18.5 to 0.20.3,
  exiftool-vendored from 29.3.0 to 38.1.0, and @azure/identity from 3.4.2 to
  4.13.3.
- Deduplicated uuid to version 11.1.1.
- Office formats now use the document converter. The OCR helper passes file paths as
  arguments instead of building a shell command; the fixes ship as install patches.

## Other fixes

- Sources enabled by a plugin or a skill's requiredSources now work in the same session.
- Provider connections are classified by endpoint protocol, not merely by whether a URL
  is present. Startup repairs affected connections, and the model picker shows one
  unified list.
- The macOS Dock icon now follows the platform's icon sizing, and a packaged app's icon
  is no longer overridden at runtime.
- PDF previews retain their existing loading and error behavior while sharing one PDF.js
  copy with the server.
