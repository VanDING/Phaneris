# Phaneris 0.1.0

Phaneris is a local-first workspace for work that continues beyond a single chat. This
first release introduces Phaneris as an independently named and maintained application
built on the open-source Craft Agents codebase.

## Work that lasts

Sessions, projects, tasks, labels, statuses, boards, and calendars persist on your
machine. Several sessions can run at once, and long-running work can continue while the
app is in the background.

A workspace-local runtime records completed operations and resumes interrupted runs. If
it cannot confirm whether an operation took effect, it pauses for your decision instead
of replaying it or reporting success.

The inbox keeps work organized by project and status, with each result linked to the
session that produced it.

## Execution you can inspect

Each session keeps a record of what was requested, which tools ran, their results,
timing, context use, cost, and any failures or recovery steps. Four views help answer
different questions: a run summary, a turn-by-turn execution ledger, the model request
as assembled, and a map of related sessions and branches. Records link back to the
conversations, files, and reviews they refer to.

The goal is to make completed work verifiable: you can distinguish confirmed results
from steps that did not finish or could not be confirmed.

## One runtime across providers

Providers share one agent kernel, event contract, tool registry, permission model, and
session lifecycle. The runtime runs in an isolated subprocess, keeping agent failures
separate from the desktop app.

Hosted providers, OAuth-backed subscription plans, cloud platforms, OpenAI- and
Anthropic-compatible endpoints, and local models use this same path. Model capabilities
and reasoning levels come from each provider rather than being hard-coded by vendor.

## A workspace you can shape

Themes are user-owned files that can control surfaces, depth, borders, shape,
typography, icon weight, and density. Set a theme for the app and override it per
workspace; partial themes inherit the rest. The built-in Default theme is intentionally
restrained and immutable.

## Local by default

Session history, profile, and activity stay on your machine. Phaneris does not publish
conversations to a Phaneris-hosted service; model requests go to the provider you
choose. Adding a model account does not notify anyone else. Documentation ships with the
app, and crash reporting stays off unless you enable it.
Your profile and activity stay local and separate from configuration. User-authored
preferences are not mixed with observed usage.

## First-release availability

This release builds from source; published installers and in-app self-update are not
available yet. Setup instructions are included in the app's Help menu.

Phaneris can be installed alongside Craft Agents, but it uses its own data directory.
Credentials must be authorized again once in Phaneris because the operating system
protects stored secrets per application.

## Baseline

- Agent kernel: Pi SDK 0.85.1
- Desktop: Electron 44.2, React 19.2
- Runtime and tooling: Bun 1.4.2, TypeScript 7, Vite 8.2
- Integrations: MCP SDK 1.29+, native REST, local, and browser tools
- Storage: local session data with a workspace-local SQLite/WAL durable runtime
