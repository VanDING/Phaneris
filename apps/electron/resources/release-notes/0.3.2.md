# Phaneris 0.3.2

This release makes planning updates share one session-backed view, adds direct
Gantt rescheduling, and brings session decisions and reliability facts into Run.
It also closes task permission gaps, repairs local file links and workspace
restoration, adds complete Simplified Chinese help, and refines themes and the
Windows installer.

## Features

- **Session decisions in Run** — Inspect decisions by feature or turn, including the actual handling, requests, outcomes and costs recorded in the session ledger. Run also shows performance metrics and decision diagnostics. Decision assistance settings focus on configuration and connection tests.
- **Local reliability facts** — Run Overview shows and exports retained terminal outcomes, unsettled effects, task budgets and conservative repetition signals. Missing observations and costs stay unknown; repetition alone is not treated as proof of a loop.
- **Gantt rescheduling** — Move and resize ordinary tasks, or edit their dates with keyboard-accessible controls. Changes use the existing planning write path, preserve inclusive end dates and show saving or failure feedback.
- **Simplified Chinese help** — All 47 registered help pages, navigation and search now support Simplified Chinese, including narrow-screen reading. The English guides also reflect current tasks, permissions, plugins and recovery behavior.

## Improvements

- **Fewer planning reloads** — Calendar and work-item consumers in the same window share their reads. Bursts of changes trigger a coalesced refresh, and successful edits remain visible when older responses arrive. Reconnecting and returning to a view revalidate its data. Calendar changes retain the backing session, and clearing a schedule only clears its dates.
- **Clearer Run views** — Decisions uses summary tiles, a feature comparison, a record table and a responsive detail drawer. Overview separates known decision cost from requests whose cost is unavailable. Failed and cancelled requests carry the matching status, and trigger details use readable fields.
- **Consistent themes** — Desktop, WebUI and Viewer share theme values, derived colors, shapes and icon rules. UI and reading scales remain distinct. Browser surfaces follow the selected theme, Viewer retains an explicit light/dark choice, and theme or scenic-image edits refresh affected views after reconnect.
- **Steadier navigation and startup** — Compact sidebar rows, icon alignment and the New Chat action share consistent spacing. Expanded and collapsed states retain focus. The shell waits for saved theme geometry and fonts before appearing.
- **Shared loading indicator** — A compact circular indicator stays legible at small sizes and across display scales, with a static visible state when reduced motion is requested.
- **Windows installer** — Welcome, progress and finish pages use one layout definition, native typography and aligned brand placement. The frame supports the system outline, rounded corners and shadow without restoring the old inset bevel.
- **Smaller production bundles and stronger maintenance checks** — Packaged builds omit the component playground and unused dependency declarations. Architecture, automation events and distribution boundaries have explicit validation gates. Completed and closed plans move to the archive, with remaining implementation decisions collected in one register.

## Bug Fixes

- **Explicit task permissions** — Tasks and resumed runs refuse missing permission declarations before dispatching a child. Declared file scopes coordinate conflicting writes, fall back conservatively to serial execution and cannot be changed when resuming a run.
- **Bound plugin confirmations** — Installation and removal confirmations bind a short-lived, single-use plan to the workspace, package and target snapshots. Contribution validation, skill rosters and availability diagnostics agree. Ordinary headers no longer imply bearer authentication, and Windows arguments preserve opaque URLs.
- **Restoring to a new location** — Workspace recovery rebases owned live Session and Artifact paths before replacement while preserving historical facts and the original workspace.
- **Clickable file links** — File links in answers open the local preview with Windows paths, file URLs, Unicode names and spaces. Markdown retains the routed file target while rejecting unsafe browser URLs and HTML.
- **Recovering a removed connection** — Existing sessions can choose another available connection when their previous one has been removed. Desktop and compact model pickers retain the recovery choices and an entry to AI settings.
- **Theme fallback and readability** — Invalid values, variable cycles, missing scenic images and unsupported syntax themes produce diagnostics and fall back to Default. Text, status colors, code overlays and Viewer highlights remain readable when themes change.
- **Menus, focus and touch** — Nested menus and tooltips appear above their parent dialogs and fullscreen views. Escape handling, restored focus and touch access to hover actions follow the active surface. Expanded sidebar tooltips no longer remain latched.
- **Accurate decision labels** — Applied recommendations no longer expose a missing translation key; failed or cancelled requests no longer appear unconfirmed. Model and feature counts use the appropriate plural forms.
- **Authentication limits** — Failed authentication is the input to authentication rate limiting, so authenticated traffic does not consume the failure budget.
