# 交互请求

代理可能需要你授权动作、提供凭据、回答问题或审阅计划。请求出现时，会话可能等待你的回应；离开窗口并不代表这些等待已经解除。

## 权限请求

需要授权的写入、命令或外部调用会显示具体动作。阅读实际路径和参数，再批准或拒绝。批准的范围以当前请求为准，不等于修改全局权限或永久允许后续操作。

拒绝时可说明原因，例如“保留原文件，请另存副本”。代理应调整方案；重复请求同一动作时，先核对目标与权限设置是否清楚。

## 凭据请求

需要 API Key、密码或 OAuth 授权时，使用专门的安全输入或浏览器授权流程。受支持的凭据会进入加密凭据存储，而不是普通聊天消息。代理可解释需要什么凭据，不应要求你把秘密粘贴进聊天记录。

秘密若直接写入聊天，可能随会话、模型上下文和导出记录保留。误发后应去原服务撤销或轮换，并处理本地记录；仅删除一条显示消息不能保证外部凭据失效。

## 计划提交

代理可提交计划文档并等待审阅。阅读后可以接受，或在接受时附带后续说明；支持的阅读界面也可标注具体段落。接受计划可能切换为允许执行的模式，应留意界面显示的权限变化。

计划卡片的接受不是通用审批节点。当前 Task 执行器只运行 session DAG，不支持 `approval: true`、loop 或条件控制节点。不可逆步骤应采用实际可用的交互和明确的执行边界，不能靠未实现的 YAML 字段获得保证。

## 用户问题

需要选择方案、补充约束等信息时，代理可以提出问题。直接回答会回到当前工作上下文；凭据仍应通过安全输入，不放入自由文本答案。

## 消息平台与无人值守

从[消息平台](phaneris://docs/messaging/overview)进入的会话，权限和凭据请求仍可能只在应用内处理。无人值守任务若需要询问，可能持续等待。出发前应明确模式、预算和可执行范围，不要为避免等待而不加区分地放宽全部权限。
