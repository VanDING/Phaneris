# 本地文件夹

本地文件夹来源把一个目录作为资料入口，适合笔记库、合同、数据集和写作材料。配置只保存路径，不会把目录自动复制或搬入工作区。

## 添加与限制访问

添加来源时选择本地类型并指定目录。使用正确的绝对路径，确认宿主账户确实有权限读取。需要写回时，优先把可写材料集中到明确的子目录，并配置相应权限规则。

来源目录不是操作系统沙箱。单靠来源名称或 guide 中的“只读”说明，不能阻止代理通过其他已授权工具访问同一文件。需要可靠只读时，还应检查来源工具规则和系统文件权限。探索模式下的文件写入仍受宿主策略约束。

## 与其他设置的关系

- [工作目录](phaneris://docs/core-concepts/working-directory)决定命令和相对路径上下文，来源不会自动替换它。
- [技能](phaneris://docs/skills/overview)可以声明所需来源，使用前仍应核对其物化、配置和连接状态。
- 工作区备份只包含工作区目录内的数据。指向外部资料目录的来源配置会被备份，但外部文件本身不会因此纳入。

## 大目录与同步目录

让来源指向实际需要的资料范围，避免一次列出过大的目录。搜索时可让代理使用现有的文件搜索工具或 `rg` 等命令缩小范围，不应假定来源会为整块磁盘建立并维护一个索引。

云盘目录中的文件可能只是占位符。使用前确认已下载到本机；同步冲突和另一程序尚未落盘的更改，也可能影响代理读取到的内容。

## 排查问题

macOS 的 Documents/Desktop 等位置可能需要在系统隐私设置中授权应用。Windows 应核对磁盘、网络盘和账户权限。写入被拒绝时，查看当前模式、工具规则及文件系统权限，而不是只重试同一动作。
