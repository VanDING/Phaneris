# 来源

来源（Source）为代理增加连接外部系统的能力。没有来源时，会话仍可在允许范围内读写文件和运行命令；接入来源后，可以使用相应服务的工具和数据。

| 类型 | 适用场景 |
| --- | --- |
| MCP 服务器 | 服务通过 Model Context Protocol 提供结构化工具 |
| REST API | 已有 HTTP API，需要配置认证、使用说明和访问策略 |
| 本地文件夹 | 将笔记库、合同、数据集等目录作为资料来源 |

## 存储与凭据

来源属于工作区：

```text
<工作区>/sources/<slug>/
  config.json        连接配置
  guide.md           使用说明
  permissions.json   可选的来源权限规则
```

凭据应通过安全输入进入加密凭据存储，不放进普通配置、guide 或聊天消息。复制来源配置不等于复制认证，目标工作区可能需要重新授权。

## 添加与使用

可以在来源面板添加，也可以让代理根据服务说明准备配置。检查服务地址、认证方式、授权范围和可能执行的本地命令，再连接并在会话中选择来源。配置存在、来源被选择、认证完成和连接成功是不同状态。

优先采用满足目标的最小权限。工作与个人账户分开配置，有助于识别操作身份。重复使用的结构化操作适合来源；一次性的网页界面操作可以使用浏览器。

## 排查问题

- **认证失败**：检查凭据是否有效、账户是否有权访问目标、OAuth 是否需要重新授权。
- **缺少工具**：核对会话是否选择了来源。MCP 工具列表通常在连接时读取，服务器更新后应重连。
- **被阻止**：检查会话模式、来源规则和限制性工具规则。策略明确拒绝的动作不应通过反复点击批准绕过。
- **插件已激活但来源不可用**：到插件详情查看缺少物化、配置、认证或执行文件等原因。激活本身不证明连接成功。
