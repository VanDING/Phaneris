# 示例与操作方法

## 读取明确页面

> 打开 status.example.com 的状态页面，告诉我哪些服务目前降级。

这是一次性调查，不必先建立长期来源。核对页面内容和时间；需要外部提交或登录时，按该操作的实际边界处理。

## 查看请求

> 在已授权的后台打开发票列表，展示加载列表时使用的接口和分页参数，不要修改发票。

有网络观察能力时，可以把界面操作与对应请求关联。转成 API 来源前，应使用受支持的认证方式并对照实际返回结果，见[API 发现](phaneris://docs/browser/api-discovery)。

## Canvas 界面

电子表格、画布编辑器或图形工具可能把内容绘制为像素，无法像普通 DOM 一样按元素定位。这时可使用名称框、搜索、菜单和明确的键盘操作。应逐步验证选中位置；坐标和快捷键会受窗口尺寸、缩放与焦点影响。

## 需要登录的流程

浏览器 Cookie 保留站点登录状态，代理可能以你的身份操作。可让代理准备表单、停在最终确认处，由你完成关键提交。事后检查页面与请求结果；不要仅凭“按钮已点击”判断业务已经成功。

## 可见的批量操作

先检查少量样本，再扩大批次。发现重复、选错对象或返回错误时应停止并核对；重试一个提交动作可能造成重复外部效果。

## 选择长期方案

周期性流程、后台无人值守或需要稳定请求语义的工作，优先评估官方 API/MCP 与[自动化](phaneris://docs/automations/overview)。网页操作可作为实际需要的路径，但不承诺跨网站、跨版本完全相同的结果。
