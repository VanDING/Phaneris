# 浏览器

桌面应用提供独立浏览器面板。启用相应工具后，代理可以导航、读取页面、点击、填写表单、截图，并使用已提供的网络观察能力。操作可见，但可见不等于所有动作都已被用户逐项批准。

## 适合的工作

一次性查询、必须通过网页操作的后台、没有合适 MCP/API 的服务，以及在授权范围内观察某项网页操作发出的请求，都适合浏览器。

重复执行或要求精确参数的流程，通常更适合配置明确的[来源](phaneris://docs/sources/overview)。网页元素、登录状态和布局会变，浏览器过程不能被当作稳定接口。浏览器依赖实际运行的桌面宿主与页面环境，不能假定无界面服务端拥有相同能力。

## 权限边界

`browserToolEnabled` 控制是否提供浏览器能力。远程代理对页面脚本执行还有额外限制。

探索模式不对浏览器的所有交互强制区分“只读”和“会修改外部数据”。打开菜单与提交表单都可能只是一次点击。代理在探索模式下应遵守仅调查的指令，但不能据此承诺登录网站绝不会被改变。

需要明确禁用此类能力时，关闭浏览器工具，或采用访问范围可核查的来源。登录会话继承你的站点权限；付款、发布、发送、删除等动作应根据具体目标获得确认，不能只依赖模式名称。

## 核查操作

结合聊天工具记录、页面状态、截图与实际请求核查结果。若请求记录可用，意外的 POST 往往比截图更能解释发生了什么。网络记录仍可能包含敏感信息，导出或复用前应脱敏。
