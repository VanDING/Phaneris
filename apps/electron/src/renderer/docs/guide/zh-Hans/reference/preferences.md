# 偏好设置

偏好保存在 `~/.phaneris/preferences.json`，用于表达姓名、时区、位置和长期交流习惯。

| 字段 | 用途 |
| --- | --- |
| `name` | 称呼 |
| `timezone` | 理解日期、日程和相对时间 |
| `location` | 地区、单位和习惯上下文 |
| `notes` | 每轮可用的长期说明 |
| `diffViewer` | 差异视图显示偏好 |
| `avatar` | 界面头像，不作为代理提示内容 |
| `uiLanguage` | 界面语言，由外观语言入口维护 |

## 写好 notes

适合记录稳定的交流要求和背景，例如“日期采用 ISO 格式”“代码遵循仓库规范”“摘要面向非技术读者”。暂时目标放在当前会话，长流程放在[技能](phaneris://docs/skills/overview)。

notes 是普通 JSON 中的文字，也会作为模型上下文使用，不要放 API Key、密码或其他秘密。保持简短并定期清理过期信息，避免把旧约束带入新工作。

## 修改与语言

通常在偏好设置界面修改，也可以明确告诉代理需要保存的长期偏好。`uiLanguage` 由外观中的语言控件统一维护，不应让其他入口各自写入。

简体中文界面打开应用内帮助时，会使用完整的中文正文与导航。语言切换保留当前帮助 slug；英文仍可正常阅读，未提供的帮助语言按默认英文回退。
