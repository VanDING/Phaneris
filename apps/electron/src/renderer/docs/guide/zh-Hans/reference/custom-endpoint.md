# 自定义端点

自定义连接适合本地模型、自建网关或兼容服务。应明确选择服务实际实现的协议，而不是根据背后模型品牌推断。

| 字段 | 说明 |
| --- | --- |
| Base URL | 例如 `https://api.example.com/v1` |
| 协议 | 如 `openai-completions` 或 `anthropic-messages`，以当前连接表单支持项为准 |
| API Key | 按服务要求配置；无认证本地服务可选相应方式 |
| 模型 id | 必须是端点真实接受的标识 |

OpenAI 兼容协议不代表背后的模型属于 OpenAI；协议、服务地址、品牌与模型能力分别管理。

## 模型能力

已知模型可采用目录信息；未知模型需要正确声明。图像输入使用端点默认值和模型级覆盖，模型级可明确关闭 `supportsImages`。思考等级也应只提供模型实际支持的选项。

错误声明可能使应用发送模型不接受的图片、参数或工具数据。模型能回答普通文字，不代表已正确实现流式工具调用。

## 修改连接

Provider、认证种类和稳定 slug 会影响执行器身份。修改后是否需要重建连接或开启新会话，应遵循当前设置的提示；正在执行的请求不会因为编辑配置自动变为新请求。

## 常见错误

- **404**：检查基础路径和调用路径是否重复 `/v1`。
- **流缺少结束标记**：核对协议、SSE 形状、tool-call delta 和网关转发；不要盲目更换协议掩盖问题。
- **只回答不调用工具**：确认服务支持当前协议的工具请求与流式返回，必要时调整网关兼容参数。
- **单个模型图片失败**：对该模型关闭图像能力，避免改变其他模型的正确设置。
- **地址只能通过代理到达**：检查应用[网络代理](phaneris://docs/reference/network-proxy)，而不只测试系统浏览器。
