# Telegram 消息

Telegram 支持会话聊天绑定，也支持工作区超级群和论坛话题，适合同时跟进多个工作流。

## 连接

1. 在 Telegram 的 BotFather 创建机器人并取得 Token。
2. 在应用消息连接入口选择 Telegram，通过安全输入配置 Token。
3. 从目标会话发起配对。
4. 在目标聊天发送 `/pair <code>`。

代码一次性、短期有效，错误尝试会消耗速率限制额度。失败后先检查有效期，不要连续猜测。

## 两级绑定

普通聊天绑定一个会话。超级群可以绑定工作区，再通过论坛话题区分会话。话题管理要求机器人具备相应群管理权限；自动化中的 `telegramTopic` 用于把生成的工作路由到明确话题。

## 指令与访问

支持 `/new [name]`、`/bind`、`/pair <code>`、`/unbind`、`/status`、`/stop` 和 `/help`。以 `/help` 返回的当前指令为准。

机器人可被其他人找到。保持 owner-only，并在应用内批准或拒绝待处理发送者。只有确实希望扩大可访问人群时才使用 open，并同时考虑这些请求能够调用的模型、来源和本地执行权限。

## 排查问题

- 无响应：检查 Token 是否撤销、平台是否启用、网络是否可达。
- 配对失败：重新生成代码，检查聊天目标和速率限制。
- 话题不可用：核对是否为正确的超级群、是否启用论坛话题、机器人是否有管理权限。
- 代理等待：回到应用检查权限、凭据或其他交互请求。
