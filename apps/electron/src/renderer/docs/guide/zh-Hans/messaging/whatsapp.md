# WhatsApp 消息

WhatsApp 通过关联设备接入，可以绑定普通聊天，也可使用自己的“给自己发消息”会话作为代理入口。

## 连接与自聊

在应用中打开连接二维码，再在手机 WhatsApp 的设置中进入关联设备并扫描。这是设备会话，行为类似 WhatsApp Web，不是独立机器人账户。手机解除关联、平台使登录失效或长时间离线，都可能需要重新连接。

连接后，在自聊中用 `/new` 新建会话，或从应用取得代码后发送 `/pair <code>`。`/unbind`、`/status`、`/stop` 和 `/help` 用于解除、检查和控制绑定。

## 运行环境与媒体

适配器通过独立的 Node worker 运行。启动失败时检查打包的 worker、所需 Node 运行时和诊断日志，不要只反复扫码。

图片、文档和长回复受平台大小与格式限制。复杂表格和丰富布局会转换为平台能够呈现的内容；需要完整交付物时，回到应用打开文件或 Artifact。

## 访问范围

当前 WhatsApp 接入没有 Telegram/企业微信那样的应用内 owner 名单。自聊适合个人访问；使用普通聊天或群聊前，应依赖平台的联系人、群成员与隐私控制明确谁能发起请求。

## 排查问题

二维码过期时重新打开连接对话框。登录被平台撤销时解除并重新关联。消息到达但回复未返回时，检查设备会话状态、网络、发送限制，以及代理是否正在等待应用内交互。

重连平台不会自动删除已有 Phaneris 会话历史；未知外部效果仍需按 Runtime 恢复语义处理。
