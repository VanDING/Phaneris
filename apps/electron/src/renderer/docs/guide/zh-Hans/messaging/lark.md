# Lark / 飞书

Lark 与飞书是独立部署。配置时先选择正确区域，再使用该部署对应的应用身份；两边凭据不能混用。

## 连接应用

在对应开发者控制台创建自建应用，取得 App ID 与 App Secret，并开通收发消息和读取所需消息内容的权限。在 Phaneris 连接入口选择 Lark 或飞书，通过安全输入配置凭据。

接收事件需要配置当前适配器支持的长连接或平台事件订阅。发送权限与接收权限是不同项；能发消息不能证明已经订阅了消息事件。若部署使用 webhook，还需确认平台能访问回调地址；仅本地运行时可优先采用支持的长连接方式。

## 会话绑定与格式

通过 `/new [name]` 或 `/pair <code>` 绑定会话，使用 `/unbind`、`/status`、`/stop`、`/help` 管理。回复使用平台支持的富文本格式，标题、链接和强调通常可保留，复杂排版仍可能转换。

## 访问控制

当前接入不提供 Telegram/企业微信同等的应用内 owner 名单。应在平台控制台限定应用可用人员、群和安装范围。组织中的应用可见范围可能远大于最初测试的个人聊天，启用前需核查。

## 排查问题

- 凭据无效：检查区域与 App ID 是否匹配，Secret 是否轮换。
- 无法接收：检查事件订阅、长连接状态、消息内容权限与应用发布/可用范围。
- 能发不能收：分别核对两组权限，不要仅凭发送成功判断配置完成。
- 指令无效：确认应用收到的消息正文符合当前 `/help` 约定，并检查是否已配对。
