# 微信与企业微信

两者是独立接入，账户、登录方式和访问模型不同。连接微信不会自动连接企业微信。

## 微信

通过手机扫描应用显示的二维码建立设备会话。状态保存在当前配置目录，以便可用时重连；平台或手机仍可以使登录失效，需要再次扫码。

当前微信接入没有应用内 owner 名单，适合边界明确的个人访问。平台联系人与会话可见性决定谁可能触达，不应将它当作已经具备组织级访问管理的服务。

## 企业微信

使用智能机器人长连接，需要配置：

| 字段 | 说明 |
| --- | --- |
| Bot ID | 机器人身份 |
| Secret | 通过安全输入提供 |
| WebSocket URL | 可选；自定义地址必须使用 `wss://` |

支持 owner-only/open、所有者名单和待批准发送者。建议保留 owner-only，并在应用中处理未知发送者。

同一 Bot ID 只允许一个有效长连接。另一工作区占用同一机器人时，应用会拒绝争用；其他运行实例也可能抢占平台连接。机器人突然无响应时，检查是否有另一实例使用了它。

此接入负责消息。企业微信文档、微盘、日程和邮件等能力需要另外配置受支持的 CLI、MCP 或[来源](phaneris://docs/sources/overview)，不能从消息机器人登录直接推导出这些权限。

## 共同操作

使用 `/new [name]`、`/pair <code>`、`/unbind`、`/status`、`/stop` 和 `/help` 管理绑定。长回复和表格会按平台格式呈现；企业微信群聊中的开头机器人提及会按适配器规则处理后传给代理。

## 排查问题

微信登录失效后重新扫码。企业微信提示 Bot ID 已连接时，先在占用方断开；Bot ID、Secret 和 URL 格式错误会明确报告。能发送却没有回复时，还需核对接收权限、连接状态、会话绑定及应用内等待请求。
