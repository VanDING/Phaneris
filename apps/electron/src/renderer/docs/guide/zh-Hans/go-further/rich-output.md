# 丰富输出

聊天可以显示表格、Mermaid 图、代码、差异和文件预览。长文或复杂材料可在工作台或阅读视图打开，不必只阅读原始 Markdown。

| 输出 | 查看方式 |
| --- | --- |
| 表格 | 结构化表格；交互能力取决于具体渲染类型 |
| 图表与流程 | Mermaid 或受支持的图表块 |
| 文档 | Markdown 阅读视图、Word/PDF 等文件预览 |
| 电子表格 | 文件 Artifact 及当前格式支持的预览，不承诺已退役的 Office 编辑引擎 |
| 图片、HTML、PDF | 按支持的格式在工作台预览 |
| 代码与变更 | 语法高亮或差异审阅 |

## Artifact

Artifact 用于把文件作为可审阅交付物管理，包含源路径、不可变修订、摘要、草稿 checkout 和状态。它与“代理直接修改了仓库文件”是不同的审阅入口。

草稿可以编辑并生成新修订，通过检查后提交为待审阅；接受时再写入正式目标。正式文件已被外部修改时可能出现冲突，系统会保留草稿，不应直接覆盖。取消草稿不会自动撤回已接受的正式文件。

预览成功不等于格式、计算和内容都正确；打开文件核对后再接受。运行终态也不会自动代表用户接受了 Artifact。

## 使用建议

明确要求适合目标的形状，例如表格用于对比、图用于表达结构、文件用于正式交付。需要长期运行的小应用时使用 Page；一次性报告则使用文档和 Artifact。已有文件也可注册为当前只读预览，不必先复制成新的草稿。
