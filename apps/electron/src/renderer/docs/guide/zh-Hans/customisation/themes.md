# 主题

当前产品仅保留 **Default**，提供浅色和深色两套配色。在「设置 → 外观」选择「系统」「浅色」或「深色」，字体偏好独立设置。

Default 浅色使用白色纸面、冷中性灰与紫色重点；深色使用石墨底色与柔和紫色。琥珀、绿色、红色分别表达注意、成功和错误。Run 使用同一配色体系，另有用于区分上下文类别的数据颜色。

## 已有设置

旧版本的 Geek、Cyberpunk 2077、Ink 和自定义主题选择统一解析为 Default。工作区主题覆盖不再生效。明暗模式和字体偏好继续保留；工作区头像、项目和看板颜色仍可独立设置。

应用不会删除或覆盖 `~/.phaneris/themes/` 下的用户文件。这些文件目前不出现在主题选择中。读取工作区设置也不会改写原文件。

## 颜色与可读性

图标、边框和填充使用原色；文字使用独立的可读颜色；实底上的文字按各自底色选择。原色满足对比度要求时直接保留，只在必要时调整文字颜色。状态底及悬停状态也参与校验，避免选中或悬停后变得难读。

启动样式、运行时快照和回退配色使用同一算法。正文和语义文字的对比度下限为 4.5:1，承载意义的图形为 3:1。用户 HTML、PDF、终端 ANSI 颜色和品牌标志保留自身配色。

## 配置与排查

应用使用 `config.json` 中的 `themeMode`、`colorTheme`、`themeFont` 作为持久偏好；颜色主题统一为 `default`。渲染缓存只服务启动，不是另一套配置权威。

如果明暗模式不符合预期，先检查外观中的模式是否为「跟随系统」。如果某个控件颜色异常，应报告具体控件与状态；内部主题契约、编译器诊断和对比度门禁用于定位问题。
