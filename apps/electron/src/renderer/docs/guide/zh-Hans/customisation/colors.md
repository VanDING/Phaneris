# 颜色

Phaneris 用语义颜色表达用途。选择 `accent` 后，由当前主题决定它在明暗界面中的具体值，避免把每个资源都绑定到某一固定色板。

| 名称 | 常见用途 |
| --- | --- |
| `accent` | 主题强调色与当前选择 |
| `info` | 信息提示 |
| `success` | 成功状态 |
| `warning` | 需要注意的状态 |
| `destructive` | 删除、失败或破坏性操作 |
| `foreground` | 中性标记与文字色 |

支持的透明度后缀如 `foreground/50`、`info/80` 会随主题解析。弱化颜色仍需检查对比度；透明度并不保证任意背景上都足够清晰。

## 使用位置

标签色用于会话标签与筛选；状态色用于状态标记；项目强调色帮助识别相关会话。看板列使用其配置支持的颜色格式，不能假定所有字段都接受同一套语义名称。

自定义颜色在支持的位置可使用明暗配对。选择时应同时核对浅色、深色、卡片和背景图上的效果；语义颜色通常更便于跨主题维护。
