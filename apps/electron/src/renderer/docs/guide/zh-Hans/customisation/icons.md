# 图标

来源、技能、状态和工具调用可显示图标，帮助在列表中识别对象。已知服务可自动匹配并缓存标识，无法可靠识别时使用中性图标，避免猜测错误品牌。

## 提供图标

各实体支持的图标字段略有差别，应以对应配置校验为准：

- 受支持的内置图标名称。
- 支持实体中的绝对本地图片路径。
- 支持实体中的单个字符图标值。
- HTTP(S) 图片地址，按该实体的下载和缓存规则处理。

常见文件格式包括 SVG、PNG、JPEG、ICO、WebP 和 GIF；实际预览能力还取决于所在入口。不要把内联 SVG 或任意相对路径写入只接受安全图标值的字段。

某些资源目录会自动发现 `icon.*`，状态也可以使用 `statuses/icons/<id>.svg`。这种约定目录发现与在 JSON 中填写路径是不同机制。下载缓存失败时应检查网络、地址和文件格式。

## 选择与工具图标

图标在小尺寸下应轮廓清楚、彼此易区分。不要只靠颜色表达状态，也不要把经常变化的优先级固定在图标中。

工具调用可通过对应配置区分 Git、HTTP 等操作。供代理使用的工具图标制作说明位于配置目录的 `docs/tool-icons.md`，可以让代理按该说明准备资源。
